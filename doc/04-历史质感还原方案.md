# 《华裳·从蚕到神》历史质感还原方案

以真实古代服饰考古与文献为依据。

为了让游戏中的服装真正具备「历史质感」，所有材质、织造、染色、形制均以考古实物、博物馆藏品与古代文献为核心参考，再在此基础上进行游戏化的视觉强化（不破坏真实触感与光影逻辑）。

## 一、核心还原原则

1. **材料真实**：优先使用古代实际存在的纤维与织物品种。
2. **工艺逻辑真实**：保留「以幅为度」、平裁、交领右衽等结构特征。
3. **视觉增强但不虚假**：光泽、垂坠、透明度可适度强化，但绝不使用古代不存在的化纤感或过度塑料光。
4. **分期明确**：不同朝代有明显差异，玩家可感知「汉唐丰腴」与「宋明清雅」的区别。

## 二、主要历史面料还原细节

### 1. 丝绸类（中国古代最高等级）

- **纱（素纱禅衣参考马王堆）**：极轻、高透明、几乎无重量感，折叠后可放入小盒。游戏中表现为超低密度、高透光、风吹即刻飞扬。
- **罗**：有孔眼的绞经织物，半透明且有明显纹理，光影下呈网状。
- **绢 / 绸**：平纹或轻微斜纹，光泽柔和，垂坠优秀，是最常用的日常与礼服面料。
- **绫**：斜纹地起花，有立体感，光泽比绸更强。
- **缎**：表面浮长线多，镜面高光明显，唐宋后逐渐流行。
- **锦（尤其云锦、蜀锦、宋锦）**：重织物，加金线或彩色纬线，厚重、挺括、金属光泽强。南京云锦的「妆花」工艺在游戏中可还原为局部彩色与金线独立控制。
- **缂丝**：通经断纬，如雕刻般的纹样效果，质地较脆硬。

### 2. 植物纤维

- **麻（大麻、苎麻）**：刚性高、吸湿好、光泽哑、褶皱生硬，是战国至唐平民与衬里的主要材料。
- **葛**：比麻更细软，但仍保持植物纤维的挺括感。
- **棉**：宋元后逐渐普及，质感介于麻与丝之间，柔软但无丝的强烈光泽。

### 3. 染色历史还原

- 严格使用古代常见植物 / 矿物染料逻辑：蓝靛（蓝）、茜草 / 红花（红）、栀子 / 槐米（黄）、苏木、皂斗、绿矾等。
- 颜色呈现自然的「脏」感与深浅变化，避免现代化工的均匀刺眼色。
- 套染与媒染会真实改变色相与牢度，游戏中可模拟「染后颜色会随时间微变」。

## 三、形制与结构还原要点

- 以「布幅」为基本单位进行裁剪（古代布幅通常约 50cm 左右）。
- 交领、右衽、宽衣大袖为默认基础（可按朝代切换）。
- 汉唐：衣身宽松、袖肥、层叠多。
- 宋明：逐渐收敛，出现更利落的褙子、袄裙。
- 里衣、中衣、外衣分层真实存在，薄纱可透出内层颜色。

## 四、19 位美人的历史质感适配建议

- **中国美人（杨贵妃、貂蝉、西施等）**：严格按对应朝代或最经典形象使用上述丝麻材质。杨贵妃偏盛唐厚重锦缎 + 轻纱披帛；西施、王昭君偏轻薄纱罗；李清照偏宋式雅致绸绢。
- **妲己、洛神、嫦娥、白素贞**：在历史丝质基础上增加神话想象，但底料仍用真实纱、罗、绸，只在特效层做文章。
- **克利奥帕特拉**：参考古埃及精细亚麻（linen），高支轻薄、褶皱自然、光泽柔和偏哑。
- **海伦、阿佛洛狄忒**：参考古希腊罗马的羊毛与亚麻披挂（Drapery），强调自然垂坠与大量褶皱。
- **小野小町**：参考平安时代的多层十二单理念，但材质转化为中国可制作的丝织品，保留「物哀」的柔光与层叠。

## 五、游戏内实现方式

- **图鉴系统**：每解锁一种历史面料，显示对应考古出处（如「马王堆素纱禅衣」「法门寺唐锦」等）。
- **制作时提示**：告知玩家当前面料的历史特点与适用形制。
- **对比模式**：可开启「纯历史还原」与「视觉增强」双模式，满足考据与视觉两种需求。
- **老化与使用感**：高级选项可模拟穿着后的轻微起皱、光泽变化，增强真实感。

## 六、参考来源（策划与美术必须对齐）

- 马王堆汉墓、法门寺地宫、定陵、黄昇墓等出土实物
- 中国丝绸博物馆、南京云锦博物馆、故宫、国博藏品
- 《天工开物》《齐民要术》等文献
- 现代复原研究成果（如中国丝绸博物馆复原项目）

这套方案能让玩家在制作和观看 Solo 时清晰感受到：这不是现代仿真丝，而是真正有历史重量的古代华裳。

需要继续细化时，可指定以下方向：

- 具体朝代面料参数对照表
- 某几位美人的完整历史服饰配置单
- 出土实物与游戏材质的对应关系
