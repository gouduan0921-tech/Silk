# 《华裳·从蚕到神》音频规格

声音负责让工艺有手感，并让 Solo 的档位差别听得出来。P1 的声音可以少，但不能用同一段循环配全部工位。

## 一、分层

| 层 | 内容 | 何时出现 |
| --- | --- | --- |
| 环境 | 桑叶、水车、染坊蒸汽、展厅安静 | 所在场景 |
| 操作 | 梭子、剪刀、针、搅拌 | 判定点 |
| 音乐 | 工位的低音量底乐、舞台的角色曲 | 织造可选，舞台必须 |
| 语音 | 30 档一句，70 档完整 | 只有演出 |

环境音在进入操作特写时降低，不彻底切掉，避免每次织布都像进入另一个游戏。

## 二、操作声

操作声要和判定结果有关。

- 织机：稳的一梭是清脆的一声；乱的一梭带摩擦杂音
- 缫丝：断头有一次短促的丝线崩断，接上后恢复连续的细声
- 染缸：搅拌稳定时水声均匀；乱搅时水声变碎
- 裁缝：剪刀每刀一声。缝制针距偏离时，布料摩擦声变干
- 人台：转身时按布料粗细换衣料摩擦。素纱轻、短；锦低、长。P1 至少做纱和绸两种

这些声音不替代画面判定。关掉音乐时，操作声仍然保留。

## 三、舞台

每位角色在 70 档有自己的音乐轮廓，与 `02` 的气质一致，不要求 P1 全部写完。

| 模板 | 音乐轮廓 | P1 |
| --- | --- | --- |
| 空灵 | 疏、慢、留白，西施与洛神一类 | 西施先做这一条 |
| 华贵 | 中速，低音乐器托住，不盖过衣料声 | P2 杨贵妃 |
| 灵动 | 节奏更密，配合踏步 | P2 赵飞燕 |
| 清冷 | 持续长音，少打击 | P2 王昭君、李清照 |
| 强势 | 重音清楚，仍然保持器乐，不做战鼓混剪 | P3 |

0 档只用环境加很轻的底乐。30 档引入主题的一半乐器。70 档才是完整轮廓。这样不看画面也能听出档位。

风力高峰不额外加一层风噪盖过人声。薄纱的声音点到为止。

## 四、语音

- 语言：中文角色说中文。克利奥帕特拉、海伦、阿佛洛狄忒若做语音，使用短句，并配中文字幕，不在 P3 之前录音。
- 70 档台词长度落在该角色分镜的最后定格之前，不覆盖整个 30 秒。
- 西施 P1 的 30 档如果来不及配音，用一声与气质相符的呼吸或无词哼唱代替，字幕写动作，不临时写一段与 `02` 无关的对白。
- 语音文件按 `角色 id_档位` 命名。

## 五、博物馆与市集

展厅默认几乎无音乐，只留房间底噪和走近展柜时极轻的布料声。主题开展幕时可以放该展览关联演出的 10 秒片段，然后回到安静。

市集不使用叫卖循环。委托牌的提示是一次木牌声。

## 六、混音优先级

同时发生时，从高到低：语音、操作判定、衣料、音乐、环境。

演出定格的最后 3 秒，音乐先收，留下衣料的余韵，方便拍照时听到衣服还在轻轻动。这和风力降到 0.3 以下是同一时刻。
