# 《华裳·从蚕到神》裁剪缝制与形制系统

本文定义布匹如何变成衣服。第一版不是自由打版，而是选择经过验证的历史形制，再调整比例和用布。

## 一、原则

- 以一幅约 50 cm 为裁剪单位，与 `04` 一致。布匹若窄于版片，必须拼幅。
- 默认交领、右衽。玩家可改为对襟，用于褙子和部分外衫。左衽不作为常规选项，避免做成错误形制。
- 衣服至少分里、中、外三层槽位。槽位可以空。空的里层使用肤色与内衣基底，不另算一匹布。
- 披帛、裙、上衣、外袍是可以分开的部件。一套礼服是部件的组合，不是一个不可拆的模型。

## 二、形制清单

| 形制 | 朝代感 | 部件 | 最早阶段 | 用布量（游戏米） |
| --- | --- | --- | --- | --- |
| 襦裙 | 通用日常 | 上襦、裙子、可选披帛 | P1 | 上衣 2.5，裙 3，披帛 1.5 |
| 直裾 | 汉 | 衣身、袖、襟 | P2 | 6 |
| 大袖衫 | 唐 | 衫、披帛 | P2 | 衫 5，披帛 2 |
| 褙子 | 宋 | 对襟长衫 | P2 | 4.5 |
| 袄裙 | 明 | 袄、裙、可选比甲 | P3 | 袄 3，裙 3，比甲 2 |

P1 只做襦裙。襦裙已经能表现层叠：里襦用绢或苎麻，外裙用绸，披帛用素纱。

跨文化角色不另做一套中国交领硬套上去：

- 克利奥帕特拉使用「裹裙 + 披挂」版片，面料走亚麻手感时读取麻行并降低摩擦 0.05、提高垂坠评价
- 海伦、阿佛洛狄忒使用「大幅披挂」版片，强调褶皱数量而不是袖子
- 小野小町使用襦裙的多层版本，层数槽从 3 提到 5，每层都是中国丝织品种

这些版片在 P3 才做。P1、P2 她们即使解锁，也先穿襦裙或大袖衫，图鉴注明「形制为暂代」。

## 三、裁剪操作

1. 选择形制和目标朝代。
2. 把布匹拖到版片上。一块布可以旋转 0 度或 90 度。纹样方向与衣身纵向不一致时，裁剪分 -10。
3. 检查幅宽。需要拼幅时，玩家指定拼缝落在侧缝、后中，或无视警告直接拼在衣身正面。正面拼缝 -15 分。
4. 调整衣长和袖宽，各有三档：窄、标准、宽。汉唐标准偏宽，宋明标准偏收。选与朝代相反的极端档，不禁止，但失去「合制」词条资格。

裁剪分：

```
裁剪分 = 100 - 纹样方向扣分 - 拼缝扣分 - 浪费扣分
```

浪费：用传世布去做里层，且外层是普通布，扣 10。这不是道德判断，而是提醒玩家把最好的布放在看得见的地方。里层仍可故意用好布，如果外层是高透明纱，则不扣，因为里层可见。

## 四、缝制操作

缝制是沿缝线推进的一段操作，不是把布料再模拟成针眼级碰撞。

- 针距保持在标记带内
- 多层交叠处要按提示的顺序：先里后外，先缝身后上袖
- 顺序错一次，缝制分 -12，外观在该缝出现拉扯法线

缝制分低于 50 的衣服可以穿，袖子摆动时额外增加不均匀拉伸，做法是把该区域的 Stretch Stiffness 降到区间低端。这让「缝坏了」在舞台上能看见，而不只是一个红字。

## 五、人台试穿

试穿使用与舞台相同的布料配置，但风是 `05` 的基础环境风，灯光是中性白。玩家可以：

- 转人台
- 开关披帛
- 单独隐藏外层，检查里层颜色
- 返回缝制调整针距，或返回裁剪更换一块版片上的布

不能在试穿界面改染色。要改色必须拆下该部件回到染坊。拆线规则见 `17`。

## 六、一套衣服的完成条件

每个可见部件都有布，缝制已确认，人台预览至少打开过一次。满足后生成成衣 ID，写入 `23`。

未打开过预览也可以强行完成，缝制分额外 -5。防止完全不看结果就入库。
