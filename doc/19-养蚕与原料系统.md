# 《华裳·从蚕到神》养蚕与原料系统

本文定义纤维如何进入仓库。输出是纱线或散纤维，还不是布。

## 一、原料种类

| 原料 | 获得方式 | 最早解锁 | 能织的品种 |
| --- | --- | --- | --- |
| 家蚕丝 | 桑园养蚕后缫丝 | 开局 | 纱、罗、绢、绸、绫、缎、锦、云锦、缂丝、改机 |
| 野蚕丝 | 夏秋在桑园外缘采集茧 | 工艺 2 级 | 纱、绢、绸。纤维偏粗，不能做素纱的传世档 |
| 大麻 | 麻田收获后绩麻 | 开局 | 麻 |
| 苎麻 | 麻田 | 开局 | 苎麻 |
| 葛 | 春夏采集 | 工艺 2 级 | 葛 |
| 棉 | 市集购买，宋代工艺后可自种 | 工艺 4 级且选择宋或以后 | 第一版不单列棉布物理行，使用苎麻行并降低弯曲 10% |

金线和彩纬不是纤维主材，是织锦时的辅料，在织造阶段加入。

## 二、养蚕

一张蚕箔一次养一批。P1 只有一张箔，P2 起三张。

一批蚕经历四态，每态至少过一天：

1. **收蚁。** 选择当季蚕种。春蚕种品质基数 80，夏 65，秋 70。
2. **喂叶。** 每天选择喂叶量和叶的新旧。喂足且叶新鲜，均匀度 +8；喂过量，湿度高，均匀度 -10，并可能生病。
3. **控温。** 拨杆保持在标记区间。离开区间的每一天，茧层分 -6。
4. **上蔟结茧。** 玩家把熟蚕拨到蔟上。放置过密，茧形分 -8。

一批结束得到茧篮。茧篮属性：

- 茧层分 0–100
- 均匀度 0–100
- 批量：小、中、大，只影响能缫出的纱线数量，不影响单根品质

生病的批次不死亡删档，产出降为残次茧，只能绩成缝线或低档绢丝。

## 三、缫丝

缫丝在蚕房水车前进行。一篮茧可分多次缫，每次消耗 2 工时，产出一束丝。

操作：

- 左手维持水温在标记带内
- 右手控制抽丝速度，使丝绪不断、不并成粗结

过程分：

```
缫丝分 = 茧层×0.4 + 均匀度×0.3 + 本次手稳×0.3
```

手稳由水温偏离和速度突变扣分。一次断头扣 8，接上后可以继续。

丝束属性：细度档（细、中、粗）、接头数、光泽潜力。

| 细度 | 适合 |
| --- | --- |
| 细 | 素纱、花纱、素罗。传世素纱要求细度细且接头不超过 1 |
| 中 | 绢、绸、绫、缎、改机、缂丝 |
| 粗 | 普通锦、蜀锦、宋锦、云锦、妆花。用来织纱会被判越级，织造分上限 70 |

## 四、麻、葛、棉

绩麻和绩葛是同一工位的不同原料。操作是把纤维对接并控制粗细，没有水温。

- 大麻默认偏粗，弯曲和摩擦走 `15` 的麻行
- 苎麻允许细一档
- 葛的原料分天然比大麻高 5，作为「比麻细、仍然挺」的手感来源
- 棉不经过绩麻小游戏，购买时自带 50–75 的原料分，避免在解锁前就做一套新玩法

## 五、仓库

纱线按束堆叠。两束只有在种类、细度档、品质档都相同，且接头差不超过 2 时才能合并。合并后品质取低的一束，防止用残丝稀释好丝的标记。

玩家可以在织机上指定消耗哪一束。系统不自动替玩家把传世细丝填进麻布。
