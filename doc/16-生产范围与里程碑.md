# 《华裳·从蚕到神》生产范围与里程碑

本文把「完整 3D 仿真游戏」拆成可以交付的阶段。完整愿景保持 `01` 不变；第一可玩版本只证明整条链能跑通。

## 一、完整愿景与第一版的差别

完整愿景包含：四季养蚕、全部 19 个细分面料、汉唐宋明形制、19 位美人三段 Solo、三座舞台、博物馆自由布展，以及之后的工坊分享。

这些不能在同一里程碑里同时做完。布料物理、染色结果和一次演出如果不同时成立，后面的内容只是在堆清单。

第一版只回答一个问题：玩家亲手做出的一块布，穿到人身上之后，看起来和另一块布不一样。

## 二、阶段定义

### P0 技术探针（4–6 周）

不做完整游戏循环。只在一个灰盒舞台上验证：

- 两层衣服：中层绸 + 外层素纱
- Chaos Cloth 使用 `15` 里素纱和绸的区间中值
- 一套风：`05` 的基础风 + 一次转身侧风
- 一套光：`08` 的白 / 素色系
- 一个定格镜头，能切到拍照机位

通过标准：1080p、布料质量为「高」时，舞台段落稳定在 60 帧附近；素纱能透出内层颜色；绸有跟随延迟。做不到这一条，不进入内容和关卡。

### P1 垂直切片（在 P0 通过后 4–6 个月）

玩家能从茧走到一件可展览的衣服。范围锁死在 `28`：

- 场景：蚕房一角、一台织机、一口染缸、一张裁桌、一座古典戏台、一个展柜
- 纤维：家蚕丝、苎麻
- 品种：素纱、绢、绸
- 染料：靛蓝、茜草
- 形制：襦裙（两层）
- 角色：西施，只做 0 阶段和 30 阶段
- 博物馆：一个展柜 + 自动收录

通过标准：一名不看文档的测试者能在 40 分钟内独立做出一件衣服，看完一次演出，并在展柜里找到它。两件不同染色的襦裙，并排时能看出颜色、透光和摆动差别。

### P2 核心工艺章（P1 之后）

- 补齐四季桑园和缫丝水车
- 织造增加斜纹和素缎
- 染色增加套染、扎染、媒染
- 形制增加直裾、大袖衫与披帛、褙子
- 角色增加到 6 位：西施、王昭君、赵飞燕、李清照、李师师、杨贵妃
- 杨贵妃只做 0 和 30；云锦不进这一阶段
- 三座舞台的布景切换可以是同一套骨骼和灯光预设，不要求三套独立关卡

### P3 高阶织物与全角色

- 按 `15` 接入蜀锦、宋锦、云锦、妆花缎、缂丝、改机
- 明代袄裙
- 其余 13 位美人的 0 阶段
- 好感满 70 的角色，按热度优先做完整 Solo，不要求 19 人同时交付 70 阶段
- 博物馆主题展和热度解锁

### P4 长期

工坊分享纹样、联机参观、少数民族形制、更多朝代。这些只留接口，不排进 P0–P2。

## 三、人员含义

文档按能分工的边界来写，不假设具体人数：

- 策划维护 `17`–`28` 的规则和表
- 技术美术维护 `15` 的 Data Asset，以及 `05` `08` `09` 的舞台预设
- 角色和服装按 `30` 的命名和分层交付
- 程序按 `23` 的数据结构存档，不在各系统里各写一份衣服格式

## 四、明确推迟的内容

以下内容在 P2 结束前不做：

- 实时三维流体充满整座染坊
- 织机上每一根经线都是 Cloth 粒子
- 19 位美人同时拥有 70 阶段语音和特效
- 玩家身体进入场景被布料碰撞（第一版只有展示用人台和美人）
- 主机认证和次世代优化
- 玩家自由缝纫任意剪裁多边形。第一版是版片选择和比例调整，不是通用服装 CAD

## 五、完成定义

对单个系统，「做完」指四件事同时成立：

1. 规则写在对应文档里，并有输入和输出字段
2. 结果能放进 `23` 的存档结构
3. 视觉变化能在舞台或展柜里被看出来
4. 有一条失败情况：原料差、节奏失误、染花、裁偏，玩家能看出它为什么比精良作品差
