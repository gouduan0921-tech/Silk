# 《华裳·从蚕到神》场景流程与垂直切片

本文把 `01` 的七个地点收成可制作的流程，并写清 P1 垂直切片的关卡内容。

## 一、完整游戏的空间结构

没有一张超大地图。玩家在地图界面选择地点，每个地点是独立场景。

```
桑园·蚕房 → 织机坊 → 染坊 → 裁缝阁 → 舞台
                 ↘ 市集 ↗            ↘ 博物馆
```

任意工坊都可以回市集。只有成衣或布匹可以进入舞台和博物馆的展示位。

场景共同规则：

- 入口处有仓库架，显示与本工位相关的物品
- 工位是场景里的一台机器或一张桌子，不是全屏小游戏菜单
- 离开场景时自动保存
- 日夜和天气在染坊、桑园可见。室内织机坊以窗户变化表示时间，不要求每间房都做动态天气

## 二、各地点的第一眼目标

| 地点 | 玩家进门后最近的可交互物 | 视觉重点 |
| --- | --- | --- |
| 桑园·蚕房 | 蚕箔 | 叶、茧、丝绪，生命感 |
| 织机坊 | 当前已解锁的那一台织机 | 经线秩序，不是满屋机器同时动 |
| 染坊 | 一口主缸 | 液面、蒸汽、晾杆上的布 |
| 裁缝阁 | 裁桌和人台 | 布摊开、剪刀、人台上的层 |
| 市集 | 委托牌 | 人少、安静，不做成喧闹集市战斗区 |
| 舞台 | 上场门 | 衣服先被看见，背景 secondly |
| 博物馆 | 最近的展柜 | 安静、可走、可停留 |

## 三、P1 垂直切片场景

P1 可以把地点做成一条室内长廊上的六个工位，不必先做七张完整美术场景。长廊只是制作方便，玩家仍然感到步骤顺序。

切片包含：

1. 一张蚕箔和一台小缫丝锅。不做四季桑林，季节在界面上显示为「春」，原料公式仍按春天计算。
2. 一台平纹织机。品种只允许绢和素纱。素纱在教学第二步之后才出现在列表里，避免第一步选择过多。
3. 一口染缸。染料只有靛蓝和茜草。
4. 一张裁桌、一个人台。形制只有襦裙。
5. 一座古典戏台。角色只有西施，档位 0 和 30。30 在好感达到 30 后出现，教学不强制。
6. 一个玻璃展柜。

切片的成功路径就是 `27` 的三个教学委托。

切片里必须能走的失败路径：

- 水温失控，丝变成粗丝，仍然能织绢，不能织传世素纱
- 搅拌失控，布出现色花
- 针距失控，袖子在 0 阶段演出里拉扯更明显

## 四、P1 不包含的场景内容

- 可进入的桑林和四季变化
- 第二台织机
- 水墨台和现代剧场
- 博物馆长厅
- 市集里的其他 NPC 对话树。委托牌可以没有人物模型

## 五、从切片扩到完整地点时的迁移

长廊工位以后拆成独立场景时，交互物的名字和存档字段不变。不允许因为换了场景就换一套物品 id。

场景美术可以重做，工艺判定不能重做。
