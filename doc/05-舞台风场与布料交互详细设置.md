# 《华裳·从蚕到神》舞台风场与布料交互详细设置

为了在美人 Solo 中让古风服饰真正动起来，舞台风场与布料系统需要高精度、可艺术控制、且性能可控。以下为完整细化方案（以 Unreal Engine 5 Chaos Cloth 为主要参考）。

## 一、舞台风场总体架构

采用**多层风场系统**，分为：

1. **基础环境风**（常驻）
   - 轻微持续风向，模拟室内通风或户外微风。
   - 默认风速：0.3–0.8 m/s
   - 方向可预设或缓慢变化（避免死板）。

2. **演出主风场**（Solo 核心）
   - 可关键的动态风源，支持关键帧控制。
   - 分为「前置风」「侧向风」「上升风」「旋转风」四种类型。
   - 支持多风源叠加（最多 4 个同时生效）。

3. **局部点风 / 冲击风**（高光时刻）
   - 用于甩袖、转身、高潮定格前的瞬间爆发。
   - 短促、高强度、有衰减。

4. **角色附属风**（可选）
   - 跟随美人移动的微风，增强披帛与袖口的跟随感。

## 二、风场参数详细设置

| 参数名称 | 取值范围 | 说明与推荐值 | 使用场景 |
| --- | --- | --- | --- |
| 风速 (Wind Speed) | 0–15 m/s | 日常 0.5–2；高潮 4–8；爆发 10–15 | 整体强度控制 |
| 风向 (Direction) | 三维向量 | 可关键帧旋转 | 制造旋转与层次感 |
| 湍流强度 (Turbulence) | 0–1 | 0.1–0.4（丝质）；0.05–0.2（厚重锦） | 避免布料过于规律 |
| 频率 (Frequency) | 0.1–3 Hz | 低频率更自然 | 控制摆动节奏 |
| 空间衰减 | 线性 / 二次方 | 距离风源越远越弱 | 精确控制影响范围 |
| 高度衰减 | 可选 | 地面强、高空弱（或反向） | 裙摆与披帛差异化 |
| 阵风曲线 | 自定义 Curve | 缓入缓出或突然爆发 | 匹配动作卡点 |

**推荐默认演出曲线**（70 阶段）：

- 0–30% 进度：微风（0.8–1.5）
- 30–70% 进度：逐渐增强至中风（3–5）
- 70–90% 进度：高潮强风（6–9）+ 湍流提升
- 90–100%：瞬间爆发后快速回落，定格时保留余韵微风

## 三、不同材质与风场的交互响应

| 材质类型 | 风场响应特点 | 推荐风速上限 | 特殊处理 |
| --- | --- | --- | --- |
| 轻薄纱 / 罗 | 极易飞扬、延迟低、层数越多越美 | 6–8 | 增加空气阻力、降低重力影响 |
| 中等绸 / 缎 | 优雅摆动、有明显跟随延迟 | 7–10 | 中等弯曲约束 |
| 厚重锦 / 妆花 | 惯性大、摆动缓慢有力、余韵长 | 8–12 | 提高质量、增加阻尼 |
| 麻 / 棉 | 响应较钝、褶皱生硬 | 5–7 | 高摩擦、低弹性 |
| 多层复合 | 外层先动、内层延迟，层次丰富 | 按外层设定 | 层间碰撞开启 |

**布料物理核心参数建议**（Chaos Cloth）：

- 弯曲刚度（Bending Stiffness）：纱 0.01–0.1；锦 0.5–2.0
- 拉伸刚度（Stretch Stiffness）：保持较高防止过度变形
- 阻尼（Damping）：0.1–0.5（越高越快稳定）
- 质量密度：按真实面料换算（纱极低，锦较高）
- 碰撞厚度与摩擦：精确到可与身体、头发、首饰自然交互
- 自碰撞：必须开启，防止布料穿透自身

## 四、与 Solo 分镜的联动设置

- 每个美人的 Solo 时间轴上预设**风场事件轨道**。
- 动作关键帧自动触发对应风力（例如赵飞燕旋转时启动旋转风；杨贵妃转身时侧向风增强）。
- 70 阶段解锁「风场艺术模式」：导演可微调每段风力，或使用预设「华贵」「灵动」「清冷」「妖冶」等风格模板。
- 定格瞬间：风力快速衰减至 0.3 以下，保留轻微飘动，方便玩家拍照。

## 五、性能与优化策略

- 近景（主角 + 3 米内）：全精度 Chaos Cloth + 高频率更新。
- 中景：降低迭代次数 + 使用顶点动画备份。
- 远景：纯顶点动画或简化布料。
- 预计算常用风场响应缓存，减少实时计算压力。
- 提供「布料质量」选项（低 / 中 / 高 / 极致），让不同硬件都能流畅运行。

## 六、调试与艺术控制工具

- 实时风场可视化（箭头 + 强度颜色）。
- 布料受力热力图。
- 一键应用「历史还原风」（较小风力）与「视觉爆炸风」（强化版）。
- 支持录制风场曲线，方便动画师微调。

通过以上设置，舞台上的每一件华裳都能根据材质不同，展现出完全不同的生命力：薄纱如烟似雾，锦缎沉稳有力，披帛随风而舞，最大程度还原并升华真实古代服饰在动态中的历史质感。
