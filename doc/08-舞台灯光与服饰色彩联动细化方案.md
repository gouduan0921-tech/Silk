# 《华裳·从蚕到神》舞台灯光与服饰色彩联动细化方案

为了让玩家制作的古风服饰在 Solo 中真正产生「色彩呼吸感」和视觉冲击，舞台灯光与服饰材质 / 染色必须深度联动。以下为完整设计。

## 一、灯光系统核心架构

舞台采用**分层灯光系统**，与布料材质参数实时交互：

1. **基础环境光**（常驻）
   柔和填充光，保证服饰暗部细节可见。

2. **主光（Key Light）**
   可移动、可变色、可变强度的主光源，决定服饰主色调表现。

3. **轮廓光 / 边缘光（Rim Light）**
   专门强化薄纱、披帛、袖口的透光与边缘高光。

4. **彩色点光 / 图案光**
   用于高潮时刻，投射对应角色气质的色光或简单纹样。

5. **动态光效**
   随动作与风场自动变化的光（呼吸、闪烁、扫光）。

## 二、灯光与服饰色彩联动规则

| 服饰基础色系 | 推荐主光色温 / 颜色 | 边缘光建议 | 高潮点光效果 | 视觉目标 |
| --- | --- | --- | --- | --- |
| 红色系（红花 / 茜草） | 3200–4500K 暖金 / 浅红 | 暖白或淡金 | 深红扫光 + 金色粒子 | 华贵、热烈、妖冶 |
| 蓝色系（靛蓝） | 5500–7000K 冷白 / 淡青 | 青白或银色 | 月光蓝 + 水波光斑 | 清冷、空灵、寂寞 |
| 黄色 / 金色系 | 2800–3800K 暖黄 / 金 | 强金边缘光 | 金色放射光 + 闪烁 | 尊贵、盛世、神性 |
| 白色 / 素色系 | 4500–6000K 中性白 | 高亮度白或淡粉 | 柔白光晕 + 轻微彩虹折射 | 纯净、通透、仙气 |
| 紫色 / 复色系 | 4000–5000K + 淡紫 | 粉紫或银紫 | 渐变紫光 + 烟雾 | 神秘、高贵、妖异 |
| 绿色系 | 5000–6500K 冷绿调 | 淡青边缘 | 翠光扫过 + 叶影 | 自然、清雅、生机 |

**联动逻辑**：

- 服饰主色会实时影响主光的推荐色相（系统可自动建议，也可手动锁定）。
- 光泽度高的面料（缎、锦）在强光下产生更锐利的高光与色移。
- 透明度高的纱罗会让边缘光大幅增强，并透出内层颜色。
- 染色「自然不均」区域在侧光下会显现更丰富的深浅变化。

## 三、三段强度灯光变化（对应 0 / 30 / 70）

- **0 阶段（克制）**
  单一柔和主光 + 低强度环境光，色温接近自然，强调历史质感。

- **30 阶段（情绪提升）**
  加入可控边缘光，主光色温开始向角色气质偏移，出现轻微动态。

- **70 阶段（完整华丽）**
  多光源协同，主光 + 双边缘光 + 点光，支持色光呼吸、扫光、瞬间爆闪，并与风场高潮同步。

## 四、角色专属灯光气质模板（示例）

- **杨贵妃**：暖金主光 + 粉金边缘，高潮时金色光雨洒落。
- **西施 / 洛神**：冷白 + 淡青，强边缘光制造水润透纱效果，伴随水波光斑。
- **王昭君**：冷蓝主光，边缘光微弱，高潮时暖光从一侧缓慢渗入。
- **妲己**：深红主光 + 妖冶粉紫点光，光影对比强烈。
- **嫦娥**：冷月白主光，银蓝边缘，高潮时月华粒子光爆发。
- **赵飞燕**：灵活跟随的侧光，快速切换制造灵动感。
- **克利奥帕特拉**：黄金主光 + 强烈方向性，突出异域金属光泽。

## 五、技术实现要点（UE5）

- 使用 Lumen + 本地光源（Spot / Point / Rect Light）混合。
- 服饰材质中加入「Light Reaction」参数，控制高光色移与饱和度响应。
- 通过 Material Parameter Collection 或 Blueprint 实时将灯光颜色传递给布料材质。
- 支持「历史还原灯光」（接近自然光）与「舞台爆炸灯光」一键切换。
- 拍照模式可锁定当前灯光，或自由调节色温、强度、角度。

## 六、与其他系统的联动

- **风场同步**：风力增强时，边缘光强度自动提升，让飞扬的布料更醒目。
- **材质响应**：光泽度越高，对色光的反射越明显；透明度越高，透光着色越强。
- **染色影响**：天然染料的「活色」在动态灯光下会有微妙的色相漂移，增强真实感。

此方案能让每一件玩家制作的华裳在舞台上随着灯光产生独特的色彩生命力，既保留历史染料的温润质感，又能在高潮时刻形成强烈视觉效果。
