# 《华裳·从蚕到神》织造系统

本文定义织机前的操作，以及一块布如何选定 `15` 里的品种行。

## 一、织机

P1 只有平纹织机。之后在同一间经纬堂解锁机型，不换场景。

| 机型 | 解锁 | 能做的组织 | 玩家操作 |
| --- | --- | --- | --- |
| 腰机 / 平纹机 | 开局 | 素纱、绢、麻、苎麻、葛 | 踏板节奏，保持纬密 |
| 多综机 | 工艺 2 级 | 花纱、素罗、花罗、绸 | 两到四片综的顺序 |
| 斜纹机 | 工艺 3 级 | 绫 | 踏板组合不能错步 |
| 缎机 | 工艺 4 级 | 素缎、花缎、改机 | 浮长组织循环更长 |
| 提花机 | 工艺 5 级 | 普通锦、蜀锦、宋锦 | 花本选择 + 投梭节奏 |
| 妆花机 | 工艺 6 级 | 云锦、妆花缎 | 在花位挖花、加金线 |
| 缂丝机 | 工艺 5 级，且完成宋代委托 | 缂丝 | 局部回纬，不是整幅投梭 |

改机使用缎机，但要求工艺等级达到明代解锁条件，见 `27`。

## 二、织一匹布的流程

1. 选择细度和品种。品种决定目标行。若丝束细度不符合 `19` 的适合表，仍可织，织造分上限下降。
2. 整经。设定幅宽和经密。幅宽默认 50 cm，对应 `04` 的一幅。玩家可选 45–55 cm。超出此范围的成衣必须拼幅，裁剪时会扣分。
3. 织造操作。按机型完成一段循环。一匹由 4 段循环组成，每段单独打分，最后平均。
4. 下机。生成布匹，长度固定为 8 米游戏长度。一件单层上衣用约 2.5 米，一条裙子约 3 米，披帛约 1.5 米。数字是游戏用量，不是考古复原用料。

## 三、操作判定

节奏点来自组织循环，不是一首无关的音乐游戏。界面在踏板和梭子上给出下一个节拍。

- 命中窗口：提前或落后 120 毫秒以内为稳，240 毫秒以内为偏，超出为乱
- 一段循环里乱的比例超过 20%，该段分数不超过 60
- 花位类组织额外检查花本是否选错。选错一次，花位分归零，布仍然可用，纹样变为错位，不能得到「流光」或缂丝的清晰纹样

织造分：

```
织造分 = 节奏×0.6 + 密度稳定×0.25 + 花位×0.15
```

没有花位的组织，花位按 100 计。

## 四、品种如何落表

玩家选的是品种名，不是直接选物理数字。

| 玩家选择 | 读取 |
| --- | --- |
| 素纱、花纱、素罗、花罗、绢、绸、绫、素缎、花缎 | `15` 同名行 |
| 锦，不指定产地 | 普通锦 |
| 蜀地花本 | 蜀锦 |
| 宋式小花 | 宋锦 |
| 挖花加金，明代 | 云锦或妆花缎。全幅妆花为云锦，局部挖花为妆花缎 |
| 通经断纬 | 缂丝 |
| 缎地起花且朝代为明 | 改机 |

然后用品质 t 在该行区间内取值，再用 `12` 的朝代偏移。偏移后若超出 `13` 里对应粗类和朝代的区间，夹到区间端点。

粗类对应：纱和罗归入轻薄纱 / 罗；绢、绸、绫、缎、改机在夹紧时分别对照 `13` 的中等绸 / 缎或改机行；各种锦对照厚重锦或云锦行。

## 五、布匹上的纹样

纹样不是另一套物理。它是布匹上的掩膜：

- 平纹素织：无掩膜
- 花纱、花罗、花缎、锦：一张花位图，决定 albedo 变化和局部法线
- 妆花和云锦：额外一张金线掩膜。金线区域光泽 +1.0（10 分制），Bend Stiffness +8%，只影响该掩膜内的着色和局部约束，不把整匹布改成金属板
- 缂丝：图案边缘额外一张刚度掩膜，Bend 和 Shear 在图案内 +15%，防止大动作把花纹拉糊

花本从已解锁图鉴里选。P1 只有「素」和「细方格」两种。

## 六、织造失败时的布

布匹不会织到一半消失。最差结果是残布：织造分低于 40。残布可以染色和做衬里，不能做外层传世成衣，也不能送去妆花。
