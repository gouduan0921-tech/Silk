# 《华裳·从蚕到神》数值与品质框架

本文是全游戏唯一的计分说明。各工艺文档只产生自己的过程分，最后都折进这里的品质、词条、热度和好感。

## 一、过程分

每一道工序给出 0–100 的过程分。过程分不是玩家直接看到的主数字，界面用「稳、偏、乱」三档提示，精确值进详情。

| 过程 | 高分在做什么 | 低分会留下什么 |
| --- | --- | --- |
| 原料 | 季节对、喂养稳、茧层均匀 | 纤维粗细不匀 |
| 缫丝或绩麻 | 水温或力度稳定 | 纱线接头多 |
| 织造 | 节奏贴合组织 | 纬密波动、花位错 |
| 染色 | 温度、时间和搅拌贴合配方 | 色花、灰暗、染不透 |
| 后整理 | 砑光力度均匀 | 光泽一块亮一块暗 |
| 裁剪 | 布幅方向和版片一致 | 纹样被切断、幅宽不够硬接 |
| 缝制 | 针距均匀、层序正确 | 拉扯痕迹、衣襟不对称 |

## 二、成衣品质分

成衣品质分 Q：

```
Q = 原料×0.15 + 成纱×0.10 + 织造×0.25 + 染色×0.15 + 后整理×0.05 + 裁剪×0.15 + 缝制×0.15
```

未染色时，染色分记 70，不奖励也不重罚，表示「素色也是完整选择」。未做后整理时，后整理分记 60。

多层衣服先算每一层的布匹分，再按层的可见权重平均。外层权重 0.5，中层 0.3，里层 0.2。披帛单独作为外层附件，不替代主衣外层。

品质档位：

| Q | 档位 | 在 `15` 区间中的取值位置 |
| --- | --- | --- |
| 0–59 | 普通 | 靠近区间低端。视觉强度偏低，物理更钝或更乱 |
| 60–84 | 精良 | 区间中点 |
| 85–100 | 传世 | 靠近区间高端，但仍被朝代夹紧限制 |

取值位置 t：

- 普通：t = Q / 59 × 0.35
- 精良：t = 0.45 + (Q - 60) / 24 × 0.25
- 传世：t = 0.75 + (Q - 85) / 15 × 0.25

最终参数 = 区间低端 + (高端 - 低端) × t。然后再乘朝代偏移，最后加上染色修正。计算顺序和夹紧写在 `21` 与 `23`。

## 三、词条

词条由过程分里的突出项生成，不由玩家手填。一件衣服最多 3 个词条。

| 条件 | 词条 | 效果 |
| --- | --- | --- |
| 素纱或花纱，且原料分、织造分都 ≥ 80 | 蝉翼 | 透明度在品种上限附近，舞台边缘光响应 +15% |
| 织造分 ≥ 85 且组织是缎或锦 | 流光 | 高光锐利度取高端 |
| 染色不均控制在配方允许范围内，不是失误性色花 | 活色 | 侧光下深浅变化更明显，博物馆讲解可点开 |
| 缝制分 ≥ 85 且多层 | 层叠 | 层间碰撞保持开启，不因性能档被简化掉最外两层 |
| 朝代与形制匹配，且裁剪分 ≥ 80 | 合制 | 展览「历史还原」得分 +10 |
| 使用非该朝代典型面料 | 越代 | 视觉仍成立，历史还原得分 -15，并在图鉴里注明 |

失误性色花不生成「活色」，只降低染色分。

## 四、舞台热度

一次演出的热度 H：

```
H = Q×0.5 + 契合×0.3 + 阶段×0.2
```

契合是衣服与角色偏好的匹配，定义见 `24`，范围 0–100。

阶段系数：0 阶段按 40 分计入，30 阶段按 70，70 阶段按 100。玩家如果只解锁了 0 阶段，热度上限被阶段压住，逼他继续提高好感，而不是只刷品质。

热度用于博物馆当日来访和委托评价，不直接改布料参数。

## 五、好感

每位美人好感 0–100。

- 首次用契合 ≥ 60 的成衣完成演出：+8
- 契合 30–59：+4
- 契合低于 30：+1，衣服仍然能穿，角色不会拒绝
- 完成该角色的主题委托：+15
- 重复穿同一件传世成衣演出：每天第一次 +2，之后不加

门槛与 `02` 一致：

- 0：解锁基础动作和基础光
- 30：加入服饰互动和边缘光
- 70：完整语音、专属粒子、高潮运镜

好感不会下降。缺少惩罚性掉好感。

## 六、历史还原与视觉增强

玩家在设置里选一种全局呈现，单件衣服也可覆盖：

| 模式 | 参数取值 | 舞台 |
| --- | --- | --- |
| 历史还原 | t 最高只到 0.55；光泽再 -10% 后夹紧 | 风力用 `05` 的偏低值，灯光接近自然色温 |
| 标准 | 按品质档正常取值 | 使用角色模板的默认风和光 |
| 视觉增强 | t 最低从 0.7 起；薄纱风力响应再 +10% | 允许 `09` 的同步强度拉到 100% |

视觉增强不能把汉代素纱变成锦的密度，也不能给麻加上缎的镜面高光。夹紧区间以 `13` 和 `15` 的高端为顶。

## 七、玩家看见什么

主界面只显示档位、最多 3 个词条、以及一句工艺来源，例如「秋茧 · 平纹绢 · 靛蓝一套」。

调试和博物馆讲解模式可以打开全部分数。普通游玩默认关掉 0–100 的过程分，避免变成电子表格。
