# 《华裳·从蚕到神》成衣与布匹数据结构

本文是存档和配置的字段说明。程序不要在养蚕、织造、舞台各自保存一套互相抄写的衣服属性。

## 一、纱线 Yarn

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 唯一 |
| fiber | enum | 家蚕丝、野蚕丝、大麻、苎麻、葛、棉 |
| fineness | enum | 细、中、粗 |
| processScore | 0–100 | 缫丝或绩麻分 |
| materialScore | 0–100 | 茧或原料分 |
| joints | int | 接头数 |
| amount | 米 | 剩余长度 |

## 二、布匹 Bolt

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 唯一 |
| variety | enum | 与 `15` 的 19 行同名 |
| dynastyStyle | enum | 汉、唐、宋、明、不限 |
| yarnId | string | 来源纱线 |
| length | 米 | 剩余 |
| width | 厘米 | 默认 50 |
| weaveScore | 0–100 | 织造分 |
| patternId | string | 花本，可空 |
| goldMask | bool | 是否有金线掩膜 |
| dyeLayers | 数组 | 最多 4 层，见下 |
| finish | enum | 无、砑光 |
| cloth | 对象 | 解算后的最终物理与视觉参数 |
| edgeDamage | 0–2 | 拆线次数 |

dyeLayers 的一层：

| 字段 | 说明 |
| --- | --- |
| dyeId | 染料 |
| strength | 0–0.85 |
| uneven | 0–1 |
| mask | 浸染为均匀；扎染、夹缬、渐变引用一张掩膜 |

## 三、参数解算顺序

`cloth` 不由玩家编辑。任何上游改动都按这个顺序重算：

1. 用 variety 取 `15` 的区间。
2. 用织造分、原料分按 `18` 得到品质档和 t。织造分权重在布匹阶段视为该项的 Q。布匹自己的档位只用原料、成纱、织造，不包含尚未发生的裁缝。
3. 套用 `12` 的朝代百分比偏移。
4. 夹紧到 `13` 中该粗类、该朝代的区间。不限朝代则夹到 `15` 原区间。
5. 按 `21` 叠加染色和后整理。
6. 写入 goldMask 的局部覆盖。
7. 若 edgeDamage > 0，Stretch Stiffness 取区间低端，光泽再 -0.2。

舞台和人台只读 `cloth`，不临时重算，除非玩家更改了呈现模式。呈现模式是视图覆盖：历史还原和视觉增强在加载演出时对 `cloth` 做一次拷贝修正，不写回仓库里的布匹。

## 四、成衣 Garment

| 字段 | 说明 |
| --- | --- |
| id | 唯一 |
| name | 玩家起名，默认为「形制 + 主色」 |
| pattern | 襦裙、直裾、大袖衫、褙子、袄裙，或 P3 的披挂类 |
| dynastyStyle | 形制目标朝代 |
| parts | 部件数组 |
| scores | 各过程分和最终 Q |
| tier | 普通、精良、传世 |
| traits | 最多 3 个词条 |
| previewSeen | 是否打开过人台 |

部件 Part：

| 字段 | 说明 |
| --- | --- |
| slot | 里襦、上襦、裙、披帛、衫、袍、披挂 |
| boltId | 使用的布 |
| lengthUsed | 米 |
| cutScore | 该部件裁剪分 |
| sewScore | 该部件缝制分 |
| clothOverride | 缝制失败时的局部刚度覆盖，可空 |

成衣的 Q 按 `18` 计算。计算时读取各部件布匹的过程分和部件分数。

## 五、角色进度

| 字段 | 说明 |
| --- | --- |
| characterId | 与 `24` 的 id 一致 |
| affection | 0–100 |
| unlockedTier | 0、30 或 70 |
| seenSolo | 各阶段是否看过 |

## 六、演出记录 Performance

| 字段 | 说明 |
| --- | --- |
| id | 唯一 |
| characterId | 角色 |
| garmentId | 成衣 |
| stage | 古典戏台、水墨台、灯光剧场 |
| tier | 0、30、70 |
| heat | 热度 |
| cameraPath | 使用的镜头预设编号 |
| presentMode | 历史还原、标准、视觉增强 |
| captured | 是否生成展演影像 |

P1 的影像是一段可回放的序列和一张定格图，不是自由摄像机录制的视频文件。

## 七、展览 Exhibit

| 字段 | 说明 |
| --- | --- |
| id | 唯一 |
| title | 展览名 |
| slots | 展柜数组：成衣或布匹，灯光预设，说明牌开关 |
| performanceIds | 可在展厅播放的影像 |
| score | 见 `26` |

## 八、命名

配置表里的品种使用拼音或英文键，界面显示中文。建议键：

`suSha` `huaSha` `suLuo` `huaLuo` `juan` `chou` `ling` `suDuan` `huaDuan` `jin` `shuJin` `songJin` `yunJin` `zhuangHuaDuan` `keSi` `gaiJi` `ma` `zhuMa` `ge`

角色键使用 `24` 的 id，不要用显示名当主键。
