# 《华裳·从蚕到神》博物馆策展系统

博物馆是成衣的归宿，也是玩家回看工艺的地方。它不重新计算布料物理，只展示已经完成的结果。

## 一、空间

P1 只有一个展柜和一面能挂定格图的墙。完整博物馆分成四区，都在同一建筑里，用门和短走廊相连：

| 区域 | 作用 | 阶段 |
| --- | --- | --- |
| 常设展厅 | 自动收录每一件成衣和每一匹剩余布 | P1 起为一个柜子，P2 起为长厅 |
| 特展厅 | 玩家自定主题、灯光和顺序 | P2 |
| 影像室 | 回放已保存的演出 | P1 起为展柜旁的一块屏 |
| 图鉴壁 | 原料、品种、染料、形制、角色传记 | P2 |

建筑外观按 `01`：玻璃和中式结构并存。室内默认使用博物馆级的均匀光照，玩家再按展柜覆盖。

## 二、自动收录

成衣完成时自动进入收藏。布匹下机时自动进入布匹库。玩家不能为了腾空格子而删除传世档物品。普通和精良可以收纳到仓库深层，不在常设厅摆出，但图鉴仍点亮。

拆掉的成衣从展厅下架，部件布匹回到布匹库。

## 三、布展

特展厅有 8 个展位。P2 先开 4 个。每个展位可以放：

- 一件成衣，使用人台
- 或一匹布，使用悬挂或平铺
- 一块说明牌，开关三项：原料来源、染料层、考古对照
- 一个灯光预设：自然、暖金、冷月、聚焦边缘、关闭彩色

展位上的布料使用「中」质量模拟加少量环境风，保证大厅里同时放 8 件时仍然可走。玩家走近到 3 米内，当前这一件升到「高」，其他件保持中。规则与 `05` 的远近分级一致。

说明牌上的考古句子来自品种数据，不由玩家自由改写成另一件文物。玩家只能写展览标题和一段 40 字以内的导语。

## 四、展览得分

```
展览分 = 平均品质×0.4 + 主题一致×0.3 + 说明完整×0.1 + 影像×0.2
```

主题一致：玩家开展时指定一个主题。

| 主题 | 一致的条件 |
| --- | --- |
| 一朝 | 展品朝代风格相同 |
| 一色 | 主染色系相同 |
| 一层一世界 | 至少三件含披帛或高透明外层 |
| 从蚕到丝 | 同时展出茧或丝束的说明、一匹布、一件成衣 |
| 传世 | 全部为传世档 |

每件不符合的展品扣主题分的相等一份。空展位不扣分，但平均品质只计算已布置的展位。少于 2 件不能开幕。

影像分：关联了至少一条 captured 演出为 100，否则为 0。

## 五、热度如何回到工艺

展览分不直接变成品质。每天第一次打开博物馆时，按展览分结算一次来访：

- 60 分以上：丝钱，见 `27`
- 80 分以上：额外给一份普通染料或缝线
- 95 分以上：点亮一则未读的文物短讯，用于图鉴

来访每天一次，防止玩家反复开关展览刷材料。换展重新开幕才重新计分，但仍受每天一次结算限制。

## 六、图鉴

图鉴条目在玩家第一次获得该对象时点亮，未获得的条目显示剪影和名字，不显示参数。

类别：纤维、品种、染料、染法、形制、花本、角色、文物对照。

文物对照只引用 `04` 已列出的公开博物馆和文献方向，例如马王堆素纱、法门寺唐锦、黄昇墓、定陵与云锦。条目正文写游戏内这项参数在模仿什么手感，不写成学术论文，也不虚构出土编号。

## 七、拍照与以后的参观

博物馆内可以拍照。P4 的联机参观只共享展览布局和成衣 id，不共享未公开的过程分。接口在存档里留 exhibit 的公开字段即可，P2 不做网络。
