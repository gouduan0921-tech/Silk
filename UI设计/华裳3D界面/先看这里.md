# 华裳 · 从蚕到神｜3D界面成果

直接体验：双击 **直接打开.html**。无需安装，无需联网。这个文件可以单独拷走。

看全部画面：双击 **效果总览.html**，并保留整个文件夹。

建议顺序：织机确认绢A → 染缸取靛蓝、搅拌、起布 → 裁上襦、裙，再留一片披帛 → 针线缝上襦与裙 → 人台确认 → 西施0档 → 放入单柜。

- 初始库存来自 docs/04 §1：丝钱40、等级1、未染绢8米、家蚕细丝4米、干靛蓝2份、干茜草1份。蚕房首日不必进入。
- 操作木牌在场景里，库存是侧架上的实物。取消或 Esc 回上一步，空格可操作当前主按钮。
- 演出时只留暂停；字幕默认开。人台或页首的「材料透光」可以看素纱与绸的同色对照。
- 成衣入柜后仍留着一片未缝披帛、1米余绢、未织细丝和未用染料。单柜只是预览，不开幕、不结算钱。
- 设置可放大文字、减少动效、重置本页体验。样板只记住自己的进度，不读取正式存档。

**这是独立界面样板。** 场景是3D风格概念图，布、人、缸不会随操作逐件变形；木牌、库存、裁片、缝合、词条示意、演出记录与展柜状态真实更新。

正式玩法以 **docs/00–29** 为准。此样板不运行工时、经验、品质、好感、热度和日结。完成牌中的普通/精良和合制用于演示信息层级，不代表已计算正式品质。工时边界见「设计方案.md」。

制作交接：看 **风格规范.md**、**素材/** 和 **参考与生成记录.md**。
实际检查：看 **验收/验收记录.md**，两种尺寸的画面分别在 **验收/1920×1080/** 与 **验收/1280×720/**。
