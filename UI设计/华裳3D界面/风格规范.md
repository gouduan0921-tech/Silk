# 一幅素纱｜界面风格规范

这份规范为《华裳·从蚕到神》的界面制定。色值、字号、尺寸与动效长度都是界面规格，不是玩法参数。玩法数字仍只引用 docs/04。

## 色与材质

| 名称 | 色值 | 使用位置 |
|---|---|---|
| 素纸 | #E8E2D4 | 页首、工位走廊、设置底面 |
| 墨灰 | #302E29 | 主文字 |
| 旧纸灰 | #6C695D | 次要说明 |
| 胡桃木 | #594637 | 实物侧架、场景木色基调 |
| 靛蓝 | #3D5963 | 主操作、完成牌、已落针标记 |
| 纸边 | #C5BDAC | 分隔线与弱边框 |
| 纱白 | #FAF6ED | 浅色文字与悬停底面 |
| 陶褐 | #855039 | 警告线与文字，必须同时配图标 |
| 选中淡灰绿 | #D2DDD9 | 选择状态底面 |
| 焦点暖杏 | #E2AE67 | 键盘焦点外线，非金色演出光效 |

墙：中性灰米，不做彩色壁画主景。木：旧而干净，保留纹理，避免漆面塑料亮点。陶：不规则细孔，液面可反光但不泛荧光。玻璃：细微边缘与低强度反射，不遮住服装。

布的透与不透属于画面的材料表现，不用不同颜色的矩形代替。素纱与绸补图用同样素色，背景格栅与叶片是否透出作为判断依据。靛蓝绢用柔和暗褶与方向性微光，不用化纤彩虹或镜面亮斑。

## 文字

标题优先用系统宋体，正文用系统中文无衬线字体，不需下载字体。字号均为界面显示规格。

| 位置 | 1920×1080 | 1280×720 |
|---|---|---|
| 品牌标题 | 30px | 26px |
| 工位名称 | 36px | 29px |
| 木牌标题 | 24px | 21px |
| 操作与正文 | 14–15px | 13–15px |
| 资源数字 | 18px | 18px |
| 旁注 | 11–12px | 10–12px |

必要操作不会只写在旁注里。放大文字到标准的1.13倍，固定的场景命中区保持原位，长木牌内部可滚动。长说明放到折叠详情。

## 画面位置

画面中心至少保留约六成横向空间给材料。页首84px，小窗口76px；工位走廊88px，小窗口76px。左木牌离边32px，小窗口24px，宽292px，小窗口270px；右侧架离边24px，小窗口18px，宽198px，小窗口178px。

走近与进入是同一个场景的两层，进入后缓慢推近。织机与裁桌用全景的局部取景；染缸、人台、戏台、柜子各用独立图。字牌不遮中心衣身，侧架不遮底部走廊。小窗口物品较多时压紧侧架间距。

## 组件与状态

| 组件 | 默认 | 交互与完成 |
|---|---|---|
| 进入提示 | 一张木牌，一个靛蓝主按钮 | 进入后推近；无全屏工序菜单 |
| 操作木牌 | 纸木浅底、细边、左侧木条 | 下一步居首；取消在下；超长内容只在木牌内滚动 |
| 主按钮 | 靛蓝底、纱白字、至少44px高 | 悬停加深；不可用时降低明度并停止点击 |
| 选项小木片 | 素纸底、灰木边 | 选中为淡灰绿底与深靛蓝边；文字与状态同时变化 |
| 实物侧架 | 木层板、折布/丝束/染料包/衣片轮廓 | 取料或铺布时选中对应物；数量与标签更新 |
| 裁片落区 | 虚线、下一步提示 | 可拖入、可点击、可键盘操作；铺布后有勾与文字 |
| 拼缝警告 | 陶褐边、浅底 | 必须显示⚠与「正面」文字，不只变红 |
| 沿缝标记 | 三个未接合标记 | 依次落针后填为靛蓝；属于手势示意，不计正式节拍分 |
| 完成牌 | 展示档位、最多三个词条、一句来源 | 过程分与记录藏在折叠详情，默认收起 |
| 工位走廊 | 顺序标号与工位名称 | 当前位浅灰绿，完成位有点标记；未满足前置时解释下一步 |
| 演出暂停 | 右上单一浅纸按钮 | 暂停确实停进度；继续恢复；0档没有换镜头按钮 |
| 说明牌 | 标题与原料/染层/汉风三项 | 标题40字内；内容开关和展示状态一起更新 |
| 字幕 | 下方浅字、柔和暗底 | 默认开，可在演出前关闭；0档无角色语音 |
| 焦点 | 暖杏外线 | Tab可见，Enter确认；Esc退一步，演出中为暂停 |

## 动效与静态图边界

场景推近约1.1秒，保持平缓。减少动效后取消场景推近过渡。演出观看段落12秒，只示意基础段落与定格，不是正式镜头时长。布、人物和缸是概念图，不随工序局部变形；素材本身的服装形态不作为库存状态判定。

## 不能出现

金色粒子、神话光效、化纤彩虹、塑料高光、黑盒剧场；大面积饱和墙色；解锁前的角色排队；用纯颜色表示拼缝风险；默认展开过程分；0档镜头切换；演出时仍有工位操作。
