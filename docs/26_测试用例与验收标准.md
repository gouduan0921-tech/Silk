# 测试用例与验收标准

版本：0.2 · 2026-10-02  
主责：什么叫可以给别人玩。数字预期全部对照 `04`，本文件不重写公式。

## 1. 发布门

首发候选必须同时满足：

1. 新档能在第 1 天用开局的绢做成靛蓝襦裙，西施完成 0 档，衣服进柜。
2. 素纱和绸在同一侧风下延迟可分。
3. 素纱能透出内层靛蓝。
4. 缝制分被压到阈值以下时，拉伸使用低端，衣服仍穿得上。
5. 读档不改变已生成的布匹 id 和染层。
6. 呈现模式切换不改仓库里的染层。
7. 关闭的角色不出现在上场门。
8. 低布料质量下颜色正确，0 档能看完。
9. 静音音乐后，织机仍有操作声。

## 2. 纯函数

| 编号 | 断言 |
|---|---|
| N1 | 未染色时染色分按 `04` 的默认，不是 0 |
| N2 | Q 在 60 和 84 的边界，档位分别是精良的两端 |
| N3 | t 乘汉偏移后，密度不低于该行低端、不高于高端 |
| N4 | 浓染强度不超过 0.85 |
| N5 | 第 5 层染挤掉第一层并扣分 |
| N6 | 边损 2 的布不能标记为传世外层 |
| N7 | 热度使用 0 档阶段分时，低于同衣 30 档 |
| N8 | 契合四项都空时等于 `04` 的底分 |
| N9 | 首发赵飞燕对素纱计品种命中；花纱启用后不再计 |
| N10 | 展览每天第二次结算金额为 0 |
| N11 | 精良布出售被拒绝 |
| N12 | 取消工序工时向上取整且至少 1 |

## 3. 流程

| 编号 | 步骤 |
|---|---|
| F1 | 教学三步按 `10` 的顺序可完成 |
| F2 | 染坏仍能做里层 |
| F3 | 拆衣后染色还在，边损增加 |
| F4 | 西施 30 档在好感到门槛前不可选 |
| F5 | 单柜预览不发丝钱；两件开幕后才发 |
