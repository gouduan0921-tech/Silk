# 配置表结构

版本：0.3 · 2026-10-03  
主责：字段和 ID。运行时对象见 `21`。数字不写在本文件，引用 `04`。

## 1. 约定

- ID 用英文键，界面用中文。
- 布尔默认 false，除非字段写明。
- 首发关闭的内容 `enabled: false`，不从工程里删表。

## 2. 品种 variety

| 字段 | 说明 |
|---|---|
| id | 如 `suSha` |
| name | 中文 |
| group | gauze / plain / brocade / bast |
| launch | 首发是否可选 |
| densityMin / densityMax | `gravity`。见 `04` §8 |
| bendMin / bendMax | 角度还原刚度。同上 |
| windMin / windMax | `wind.influence`。同上 |
| glossMin / glossMax | 同上 |
| opacityMin / opacityMax | 同上 |
| stretchGroup | 指向 §8 的分组，不在每行重复一套拉伸 |

| liningOnly | 只能做里层（`04` §8「是，仅衬里」） |

首发 id：`suSha`、`juan`、`chou`、`zhuMa`。

全部 id：素纱 `suSha`、绢 `juan`、绸 `chou`、苎麻 `zhuMa`、花纱 `huaSha`、素罗 `suLuo`、花罗 `huaLuo`、绫 `ling`、素缎 `suDuan`、花缎 `huaDuan`、普通锦 `puTongJin`、蜀锦 `shuJin`、宋锦 `songJin`、云锦 `yunJin`、妆花缎 `zhuangHuaDuan`、缂丝 `keSi`、改机 `gaiJi`、麻 `ma`、葛 `ge`。

## 3. 染料 dye

| 字段 | 说明 |
|---|---|
| id | `indigo` `madder` `gardenia` `safflower` `pagoda` `sappan` `acorn` `vitriol` |
| role | color 或 mordant |
| launch | 靛蓝、茜草、栀子为 true；工艺章另开红花、槐米、苏木、皂斗、绿矾 |
| bestSeason | spring / summer / autumn / any |

## 4. 形制 pattern

| 字段 | 说明 |
|---|---|
| id | 首发只有 `ruQun`；工艺章 `zhiJu`（直裾）、`daXiuShan`（大袖衫）、`beiZi`（褙子）、`aoQun`（袄裙） |
| parts | 槽位列表 |
| dynasty | han / tang / song / ming |
| launch | |

槽位：`inner` `upper` `skirt` `drape` `robe` `wrap`。直裾的袍与大袖衫的大袖都用 `robe`（外层）；褙子用 `wrap`（中层）；袄裙的袄用 `upper`。

| 字段 | 说明 |

| template | airy / cold / lively / rich / strong |

| enabled | 非首发角色 false |

## 6. 舞台 stage

| id | launch |
|---|---|
| `stage_classic` | true |
| `stage_ink` | false |
| `stage_modern` | false |

## 7. 委托 quest

| 字段 | 说明 |
|---|---|
| id | |
| need | bolt 或 garment 的条件：品种、染料、最低档 |
| days | 期限，见规则层，不在本表写第二套工时 |
| rewardAffection | 可空 |
| tutorial | 前三个为 true，刷新逻辑不随机替换它们。id 为 `tutorial_1`、`tutorial_2`、`tutorial_3` |

## 8. 活动 activity

`enabled` 默认 false。允许修正的字段只有：某染料当季强度系数、展览丝钱上限。不允许改品质公式。

## 9. 校验

加载时检查：

- 每个首发品种在 `04` §8 有行
- 角色偏好的品种 id 存在
- 首发形制的部件都有槽位
- 启用的角色，其 `launchTierMax` 不超过 30；首发三位里除西施外不超过 0；工艺章里杨贵妃可到 30，李清照不超过 0
- 关闭的篇章角色 `enabled: false`；启用的只有 `16` §2 表里的角色
