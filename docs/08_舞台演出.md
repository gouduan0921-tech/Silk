# 舞台演出

版本：0.3 · 2026-10-03  
主责：一次 Solo 如何由动画、风、光、衣服装配。风速和色温见 `04` §9。角色模板见 `16`。

## 1. 输入

角色、已解锁档位、成衣、舞台、呈现模式、镜头路径。

输出一条演出记录。定格可以另存一张图。

## 2. 档位删减

分镜原文不另写三套。低档是删，不是改故事。

| 档 | 动作 | 风 | 光 | 语音 |
|---|---|---|---|---|
| 0 | 第一段和定格 | 只有基础风 | 一盏柔光 | 无 |
| 30 | 加上行走和转身 | 不超过 `04` 的 30 档上限 | 主光加一条边缘光 | 最多一句 |
| 70 | 完整 | 四段节奏 | 角色色 + 色系推荐 | 完整。首发不做 |

首发西施做到 30。王昭君、赵飞燕只有 0。

## 3. 轨道

一条 Unity Timeline 上四条轨道：动画、MagicaWindZone、灯、摄像机。

有对应动作才挂事件：

- 转身：侧风，镜头开始绕，边缘光提高
- 甩袖最高点：短冲击风，推近
- 定格前：风降到 `04` 的余韵值，光回到轮廓

0 档没有转身事件就不挂侧风。

标准时长按角色分镜，不拉长去凑满 30 秒。百分比仍是铺垫、发展、高潮、余韵。0 档可以只有铺垫和余韵。

## 4. 衣服

外层和披帛读成衣的 `cloth`。呈现模式改拷贝。

词条「蝉翼」「层叠」的效果见 `04` §6。层叠保留哪些实时层，见 `03`。

染色色系可以选择推荐主光。玩家能在开演前锁定色温。

## 5. 拍照

余韵最后一段可以切预设镜头。首发 0 档只有一条路径。自由相机留到 30 档，限制在舞台盒子内，不能穿进布料。

## 6. 验收

- 0 档没有粒子也能认出袖和裙。
- 素纱襦裙和绸襦裙的延迟肉眼可分。
- 历史还原下没有爆闪。
