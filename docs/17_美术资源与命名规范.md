# 美术资源与命名规范

版本：0.4 · 2026-10-06  
主责：资产怎么命名、交付到什么程度才算进游戏。

## 1. 命名

用 `05` 的英文键。中文只出现在界面。

| 种类 | 例子 |
|---|---|
| 角色 | `SK_xiShi` |
| 部件 | `SK_part_skirt` |
| 材质 | `M_cloth_suSha` |
| 花本 | `T_pattern_grid` |
| 演出 | `LS_xiShi_t0` |

## 2. 角色

共用骨架层级。角色从 Blender 导出 FBX，导出约定见 `29`。首发交付西施的近景面部、衣身 `MagicaCapsuleCollider`、可关的头发链。王昭君和赵飞燕可以后到，但没有 Timeline 就不能在上场门显示。

## 3. 衣服

按部件，不按「一套死模型」。首发：上襦、裙、披帛。每件挂 MagicaCloth 的 MeshCloth。颜色和纹样全部走 URP 材质实例，模型不带死颜色。

袖和衣身分开，便于以后换袖宽。首发三档宽窄优先用缩放，缩放破坏布线才另做拓扑。

## 4. 面料纹理

每个启用品种要有：中性底色、结构法线、粗糙度。纱必须有透明度掩膜。玩家的染色是另一张掩膜，不画进底色。贴图在 Krita 绘制，色彩空间见 `29`。

## 5. 场景

首发可以是走廊上的工位。染缸、梭、剪刀的精度高于墙。舞台背景让出衣服轮廓。

## 6. 验收

品种进游戏前：`04` 有行，染色掩膜能覆盖，和绢并排能看出文档里写的那一项差别。切到低质量时颜色仍对。

## 7. 接入口

正式美术不改代码：按下表的名字放进 `Assets/HuaShang/Resources/HuaShang/Art/`，有就用，没有就退回灰盒。菜单「HuaShang/美术/生成美术接入清单」列出已有和缺的资产（写到 `Assets/HuaShang/Art/美术接入清单.md`）。

| 类 | 路径与名字 | 约定 |
|---|---|---|
| 角色 | `Characters/SK_{角色 id}` 预制体 | 脚底在原点，面朝 −Z，身高约 1.6 米。只换外形；布料碰撞仍用灰盒胶囊 |
| 衣片 | `Garments/SK_part_{槽位}_{形制 id}` 网格 | 网格在人体根节点空间；uv.v ≥ 0.999 为固定，≤ 0.9 可动，同灰盒绘制约定 |
| 面料 | `Fabrics/T_fabric_{品种 id}_n` 法线 | 可平铺；走 URP 细节法线，平铺 40×60，不改颜色。程序生成的一套已放入，Krita 交付后同名覆盖 |
| 场景 | `Props/SM_{工位 id}`、`SM_workshop`、`SM_stage_classic`、`SM_stage_ink` | 放在工位原点；工位里会动、会变色的部件（梭、缸面、晾布、针等）保留灰盒，其余灰盒隐藏。人台、展柜不整体替换 |
| 音效 | `Audio/A_sfx_{名字}` | 名字见清单；没有的用合成占位音 |

模型用 Blender 做（Blender MCP），脚本在 `tools/blender/`：`hs_art.py` 是工具库（坐标一律按 Unity 写，导出时换算），`loom.py` 四台织机、`props.py` 其余工位与工坊、`stage.py` 两套戏台、`character.py` 十九位角色。导出的 FBX 只带材质名，由菜单「HuaShang/美术/更新材质库并重映射模型」换成 `Assets/HuaShang/Art/Materials` 里的 URP 材质（木、漆、灰泥、纸、陶、竹、石、铜等，贴图程序生成）。

人体本地朝 +Z（手臂前伸，披帛搭在 -Z 的肩后）；人台、戏台、展柜把人体挂在转了 180° 的节点下，正面对着镜头。角色模型按同一约定朝 +Z。

衣片网格仍用程序生成（`GarmentShapes`），因为它们要按绘制约定挂 MeshCloth；正式衣片按上表命名放入即替换。
