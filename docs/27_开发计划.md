# 开发计划

版本：0.3 · 2026-10-03  
主责：顺序和退出条件。不另写公式。范围以 `00` §6 为准。

## 1. 起点

2026-10-02。工程尚未建立可玩场景。`doc/` 是散稿。本手册是规则基线。

## 2. 原则

1. 先做数据和纯函数，再做人台和舞台。
2. `04` 的表进 ScriptableObject。代码里不出现第二套重力或弯曲数字。
3. `26` 的 N1–N12 先在无头测试里过。
4. `03` 的四条视觉证明没过之前，不加第四个品种。
5. 首发关闭的角色和舞台保持关闭。

## 3. 里程碑

| 编号 | 名称 | 主文档 | 退出条件 |
|---|---|---|---|
| P0 | 表和存档 | `04` `05` `21` | 表能加载；schema 1 能读写；N1–N6 通过 |
| P1 | 布料探针 | `03` | `03` §5 四条在灰盒舞台通过 |
| P2 | 工位链 | `02` `07` `12` | 从织到人台，不看舞台也能看清素纱和绸 |

体量不写成人月。顺序不能倒过来：没有 P1，就不做 P4 的粒子。

## 4. 首发之后

工艺章才打开 `04` 里标记为非首发的品种行，并实现直裾、大袖、更多角色的 0 档。70 档按角色一个一个做，不并行铺 19 套语音。
