# 织染裁缝工序

版本：0.2 · 2026-10-02  
主责：织、染、裁、缝何时算成功、何时留下瑕疵。所有阈值见 `04` §5、§8。

## 1. 织

首发只有平纹机，可选素纱、绢、绸。苎麻不在这台机器上织，里层使用开局或购买的苎麻布，首发不单做绩麻小游戏。

流程：选品种、整经、四段循环、下机。

节拍打在踏板和梭上。稳、偏、乱的毫秒窗口见 `04`。一段里乱的比例超过阈值，该段分数被封顶。

下机得到 8 米布。花本首发只有「素」和「细方格」。选错花本时布仍在，花位分归零。

残布：织造分低于 40。可染，可做里层，不能做传世外层。

## 2. 染

首发染料：靛蓝、茜草、栀子。一口缸。

操作：浓度三档、水温、起布、搅拌。强度和叠色公式见 `04` §5。

出缸后颜色烘焙。晾晒只播放由湿到干，不继续改配方。写入存档的是干态。

扎染、夹缬、绿矾、砑光留在表里，首发工位不提供。

色花写成掩膜。它降低染色分，不删除布匹。

## 3. 裁

首发形制只有襦裙：上襦、裙、可选披帛。

布可以 0 度或 90 度铺上版片。方向不对、拼缝在正面、浪费好布，扣分见 `04`。外层是高透明纱时，里层用好布不扣浪费。

衣长和袖宽三档：窄、标准、宽。首发标准档对应汉风，偏宽。选极端档仍可做，但拿不到「合制」。

## 4. 缝

沿缝推进。针距离开标记带则摩擦声变干，并扣缝制分。层序必须先里后外。

缝制分低于 50 的部件仍可穿，拉伸刚度取该品种低端。

未打开人台就入库，额外扣分，见 `04`。

## 5. 人台

使用与舞台相同的布料配置，风只用基础风，光用中性白。可以转、隐藏外层、退回缝或裁。不能在这里改染料。改色必须拆下部件回染坊。拆衣规则见 `02`。

## 6. 完成

每个可见部件都有布，缝制已确认，人台至少打开过一次（或接受扣分强行入库）。然后生成成衣。
