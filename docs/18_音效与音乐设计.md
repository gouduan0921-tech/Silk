# 音效与音乐设计

版本：0.2 · 2026-10-02  
主责：哪一层声音在什么时候响。不写具体波形文件名以外的第二套演出规则。

## 1. 层

| 层 | 内容 |
|---|---|
| 环境 | 蚕房、缸、展厅底噪 |
| 操作 | 梭、剪刀、针、水 |
| 音乐 | 工位很轻，舞台按模板 |
| 语音 | 首发不做 70 档。30 档西施若来不及配音，用无词短音，字幕写动作。高阶织物的西施、杨贵妃 70 档同样处理，配音交付后替换 |

关掉音乐时，操作声仍在。

## 2. 操作声和判定

稳的一梭清脆。乱的一梭带摩擦。断头一声短响。搅拌乱时水声变碎。针距偏时布声变干。

素纱的摩擦轻而短，绸更沉。首发至少这两套。

## 3. 舞台

0 档只有环境和很轻的底乐。30 档加入空灵模板的一半乐器。70 档的完整轮廓首发不做。

定格前音乐先收，留下衣料余韵，和风收回是同一时刻。

混音从高到低：语音、操作、衣料、音乐、环境。

## 4. 展厅和市集

展厅默认几乎无音乐。首发市集如果只有委托牌，提示是一次木牌声，不循环叫卖。

播放用 Unity 自带音频。FMOD 与 Wwise 的启用条件见 `29` §6。
