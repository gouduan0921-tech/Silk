# 视觉风格指南

版本：0.2 · 2026-10-02  
主责：画面气质和什么不能出现。灯光数值见 `04` §9，联动规则见 `15`。

## 1. 风格名

「一幅素纱」。安静，材料先被看见，建筑退后。

## 2. 工位

- 蚕房：叶、茧、丝绪。不要金色粒子。
- 织机：经线整齐。不要满屋机器同时大幅动画。
- 染缸：液面和晾杆上的布是特写。蒸汽淡。
- 裁桌：布摊开，剪刀和针能看清。
- 舞台：背景亮度低于衣服受光面。木色戏台，首发不做黑盒子剧场。
- 展柜：玻璃、中性墙。灯可以暖，墙不抢衣服。

## 3. 禁止

- 塑料高光、化纤彩虹。
- 用 UI 色块代替布的透与不透。
- 神话光效出现在首发汉风演出里。
- 把麻做成缎的镜面。

## 4. 人物

面部要经得起定格。衣服轮廓优先于背景雕刻。首发只要求西施达到近景，另两位可以同一精度，但不为未启用角色做高模。
