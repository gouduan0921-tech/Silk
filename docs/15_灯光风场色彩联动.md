# 灯光风场色彩联动

版本：0.3 · 2026-10-03  
主责：光、风、镜头谁跟谁。风速、色温、边缘光增幅见 `04` §9。

## 1. 风的四层

基础环境风常在。演出主风分前置、侧向、上升、旋转。冲击风只给甩袖和定格前。角色身边的小风可选，首发不做。

0 档只用第一层。

## 2. 和衣服

纱对小风敏感，锦要更大的风才动。敏感度已经在品种的风力系数里，不在灯光文档再写一套倍率。

薄纱被吹起时，提高透光处的边缘光。这是显示规则，幅度见 `04`。

## 3. 和色

主色选择推荐色温：红暖、蓝冷、黄更暖、素色中性。玩家可锁定。

光泽高的缎和锦，高光更窄。透明度高的纱，边缘光更明显。这些是 URP 材质实例对同一盏灯的响应，不换灯具数量。风源用 MagicaWindZone。

## 4. 和镜头

推近时对比略增。仰拍加强轮廓。定格前风和光一起收回，避免纹样糊掉。

首发 0 档镜头不快切。

## 5. 三座舞台

古典戏台从首发启用。水墨台在二轮 36 级启用：浅宣纸色天幕，淡墨远山层层退远，地面灰白，台口不设木柱；主光偏冷一档，边光加强，衣色在浅底上更显。现代剧场的 id 留着，`enabled: false`。换舞台不改品质和契合，演出记录写下用的是哪座台。
