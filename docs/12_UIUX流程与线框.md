# UI / UX 流程与线框

版本：0.2 · 2026-10-02  
主责：工位上玩家看见什么、先看见什么。键鼠为首发。手柄以后按同一焦点顺序映射。

## 1. 进入工位

走近，一个主提示。进入后镜头推近，不弹出脱离场景的全屏菜单。取消退回上一步。

库存在工位侧面的架子上选。

## 2. 三层信息

| 层 | 内容 |
|---|---|
| 操作中 | 下一步。不显示弯曲刚度这类词 |
| 完成时 | 档位、最多 3 个词条、一句来源 |
| 详情 | 过程分、是否被夹紧。默认折叠 |

来源句例子：「精良 · 秋茧平纹绢，靛蓝一套」。首发季节固定为春，句式仍保留，避免以后改文案结构。

## 3. 首发每个门

| 门 | 主操作 | 确认的结果 |
|---|---|---|
| 蚕箔 | 喂叶、温度 | 一篮茧。首日可以不进 |
| 织机 | 节拍、选品种 | 一匹布 |
| 染缸 | 浓度、起布、搅拌 | 染后的布 |
| 裁桌 | 拖布到版片 | 部件 |
| 针线 | 沿缝 | 缝合 |
| 人台 | 旋转、藏外层 | 入库 |
| 舞台 | 选已解锁的人 | 开始 |
| 柜子 | 放入 | 预览或开幕 |

织机和缝制的判定发生在节拍上，不发生在结算按钮。结算只表示接受这个结果。

键鼠（首发）：节拍键为空格（织、缝、缫、搅拌）；Enter 确认木牌主按钮；Esc 退一个画面层级，演出中 Esc 与空格为暂停；Tab / Shift+Tab 移动焦点；人台上 A / D 或拖动旋转；30 档演出中 C 切换镜头、按住右键转自由相机。

## 4. 演出中

隐藏工位提示。只留暂停。30 档额外留镜头切换。不在演出中改衣服或风力。

## 5. 列表

首发选项少，用架子上的实物表示，不先做长列表。未解锁角色不排在上场门前。

## 6. 可读性

节拍除了窗口还有声音。拼缝警告有图标，不只靠颜色。字幕默认开。文字大小可调，不改变 3D 命中区。

调试面板可看当前品种行，发行版本关闭。视觉增强不是这个面板。
