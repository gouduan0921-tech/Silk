# 开发工具

版本：0.5 · 2026-10-03  
主责：每件工具做到哪一步算交付。布料数字见 `04`，解算字段见 `03`，文件名见 `17`。

## 1. 清单

| 工具 | 这台电脑 | 用在哪 |
|---|---|---|
| Unity 6（6000.6.4f1）+ URP | 已安装，工程已建 | 工坊、人台、舞台、展柜、Timeline |
| MagicaCloth 2 | 已导入，目录 `Assets/MagicaCloth2` | 人台、舞台、近处展柜的布 |
| Blender | 已安装 | 西施、上襦、裙、披帛，导出 FBX |
| Krita | 已安装 | 底色、法线、粗糙度、纱的透明掩膜、染色掩膜 |

Cocos 和虚幻不进这条流水线。Marvelous Designer、CLO、Style3D、Houdini、Substance、FMOD、Wwise 见 §6，首发不用，以后可能用到。

## 2. Unity 6 + URP

工程在仓库根目录，编辑器版本锁在 `6000.6.4f1`。URP、Timeline、Input System 已在包清单里。

Unity 负责场景、玩法脚本、存档、`05` 对应的 ScriptableObject、URP 材质实例、灯光和声音的播放。舞台一条 Timeline，四条轨道的分工见 `08`。

编辑器里直接 Play 就是日常验收。`com.unity.modules.cloth` 是引擎自带布料模块，不代替 MagicaCloth 2。布料数字只从 `04` 写入，不在 Inspector 里另存一套。

镜头用 Cinemachine，从 Package Manager 添加。给玩家出 Mac 安装包时再装完整 Xcode；编辑器里试玩不需要。

## 3. MagicaCloth 2

只挂在人台、舞台角色和近处展柜。织机的线、染液、远柜不用它，见 `03`。

插件已在 `Assets/MagicaCloth2`。其中 `Example (Can be deleted)` 是官方示例，不放进首发场景。品种预设放 `Assets/HuaShang/Cloth`，见 `20`。

每个衣服部件一个 MeshCloth。身体碰撞用 `MagicaCapsuleCollider`，风源用 `MagicaWindZone`。写入字段只有 `03` 那几项：重力、角度恢复刚度、风力影响、阻尼、距离约束刚度。改完 `SerializeData` 要调用 `SetParameterChange()`。

低质量关掉 MagicaCloth 组件，蒙皮动画、颜色和透明度留着。

## 4. Blender

只出模型和骨架。首发交付：西施，以及上襦、裙、披帛三个部件。王昭君、赵飞燕可以后到，见 `17`。

袖和衣身分成两个网格。单位与游戏一致，1 单位 = 1 米，衣服尺寸仍以 `04` 的形制表为准。导出 FBX：应用缩放，向前 −Z、向上 Y，带骨架。修改器在导出前应用。

网格不烘焙玩家的颜色和纹样。染色、光泽、透明度进 Unity 之后由材质实例写，见 `17`。

## 5. Krita

只出贴图，不改网格。每个启用品种一套：

| 贴图 | 内容 | 进 Unity |
|---|---|---|
| 底色 | 中性明度，不带玩家染色 | sRGB |
| 法线 | 纱孔、绢纹、绸纹 | Non-Color |
| 粗糙度 | 结构，不写光泽分 | Non-Color |
| 透明掩膜 | 只有纱要 | Non-Color |
| 染色掩膜 | 哪里吃色，与底色分开 | Non-Color |

文件名按 `17`。光泽和透明度的 1–10 分不画进贴图，由 URP 材质实例按 `04` 写。

## 6. 后期才考虑

下面这些首发不装、不进工程。品种、形制或声音层变多之后，收益才明显。真要启用，先改本章，再替换下表里「现在谁做」的那一环。运行时引擎仍是 Unity 6，布料数字仍只在 `04`。

| 工具 | 现在谁做 | 以后可能接什么 |
|---|---|---|
| Marvelous Designer、CLO、Style3D | Blender 出部件网格 | 形制超过襦裙、要按纸样出裁片时，出服装网格，仍以 FBX 进 Unity。运行时布料仍是 MagicaCloth 2 |
| Houdini | 织机用动画，染缸只做特写 | 经线或整缸流体要烘焙时，出烘焙结果。粒子不写回物品，见 `03` |
| Substance | Krita | 启用品种变多、贴图要成套生成时，出底色、法线、粗糙度和掩膜。色彩空间仍按 §5 |
| FMOD、Wwise | Unity 自带音频 | 舞台音乐层和语音档变多、要按状态切换时，接管播放。哪一层何时响仍见 `18` |
