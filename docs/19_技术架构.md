# 技术架构

版本：0.3 · 2026-10-03  
主责：模块划分。仿真边界的细则在 `03`。数字在 `04`。

## 1. 引擎

Unity 6，渲染管线 URP。服装用 MagicaCloth 2 的 MeshCloth，要求 Unity 2022.3 或更新；首发用 Unity 6。角色和衣服从 Blender 以 FBX 导入。首发目标是 1080p、布料质量高、演出接近 60 帧。最低档关掉布料组件，只留蒙皮，允许 30 帧。不发布 WebGL：MagicaCloth 2 不支持。

## 2. 模块

| 模块 | 写 | 不写 |
|---|---|---|
| 存档 | `21` 的结构 | 材质 |
| 工艺 | 分数、掩膜 | `cloth` 浮点 |
| 解算 | `cloth` | 玩法规则 |
| 演出 | 演出记录 | 仓库原件 |
| 展览 | 展位和当日标记 | 远距离高精度布料 |
| 界面 | — | 另一份品质分 |

## 3. 步进

工艺在玩家确认时结算。养蚕的每天结算发生在工坊日结束。镜头不在蚕房，到期的一天仍然生效。这是首发里唯一的离屏结算。织和染不在离屏自动完成，因为它们有手操作。

## 4. 随机

委托刷新和以后的天气用 `hash(档 id, 日序)`。读档不重掷。首发春、无天气玩法，哈希先接在委托上。

## 5. 首发不做的技术

每根经线的粒子、整缸持久流体、19 人同时登台的布料、主机认证、WebGL。
