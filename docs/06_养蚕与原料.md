# 养蚕与原料

版本：0.2 · 2026-10-02  
主责：茧和纱如何产生。分数和季节基数见 `04` §3。工时见 `04` §2。

## 1. 首发原料

| 原料 | 做法 | 用途 |
|---|---|---|
| 家蚕丝 | 养蚕后缫丝 | 素纱、绢、绸 |
| 苎麻 | 开局库存或以后绩麻 | 只作里层 |

野蚕、大麻、葛、棉在表中存在，首发不出现在工位列表。

## 2. 一批蚕

首发一张蚕箔。四步，每步至少过一天：收蚁、喂叶、控温、上蔟。

输出茧篮：茧层分、均匀度、批量。批量只决定能缫几束，不提升单束品质。

控温离开标记带的每一天，按 `04` 扣茧层。喂叶和上蔟的加减分也只引用 `04`。

生病不删档，产出残次茧，只能做缝线或低档绢丝。

## 3. 缫丝

一篮可分多次。一次 2 工时，一束丝。

玩家维持水温和抽丝速度。断头按 `04` 扣分，可以接上继续。

细度三档：

| 细度 | 首发用途 |
|---|---|
| 细 | 素纱。传世还要求接头不超过 `04` 的上限 |
| 中 | 绢、绸 |
| 粗 | 不能做传世素纱。织纱时织造分上限见 `04` |

## 4. 仓库

两束只有种类、细度、品质档相同，且接头差不超过 2，才能合并。合并后品质取较低的一束。

织机必须由玩家指定消耗哪一束。系统不把细丝自动填进麻布。
