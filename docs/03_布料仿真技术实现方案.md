# 布料仿真技术实现方案

版本：0.3 · 2026-10-03  
主责：哪些效果实时解算，哪些烘焙。参数区间见 `04` §8。品质如何取区间见 `13` 与 `04` §4。

## 1. 两层仿真

| 层 | 玩家在做什么 | 实现 |
|---|---|---|
| 工艺 | 养蚕、抽丝、织、染、裁、缝 | 规则、动画、计分。结果写入物品 |
| 视觉 | 人台、舞台、近处展柜 | MagicaCloth 2 的 MeshCloth + URP 材质实例 |

织机上的经线是动画和节拍，不是成千上万的布料粒子。染缸只在特写镜头里做液面。布离开染缸后，颜色烘焙进纹理。

## 2. 参数从哪来

顺序固定：

1. 按品种取 `04` §8 的区间。
2. 按品质档取区间内的位置 t。
3. 乘朝代偏移。
4. 夹紧到该品种区间，不允许漂出表外。
5. 加染色和后整理修正。
6. 金线掩膜只改局部光泽和局部弯曲。
7. 边损和缝制失败覆盖拉伸。

舞台加载时如果呈现模式不是标准，在拷贝上再夹一次，不写回仓库。

写入 MagicaCloth 2 时，每个服装部件一个组件。改 `SerializeData` 后调用 `SetParameterChange()`。

| `04` 的列 | 写入字段 | 首发固定、不按品种分的项 |
|---|---|---|
| 密度 | `gravity`（0–10） | `gravityFalloff` = 0 |
| 弯曲 | `angleRestorationConstraint.stiffness`（0–1） | `triangleBendingConstraint.stiffness` = 1 |
| 风力 | `wind.influence`（0–2） | 风源用 MagicaWindZone |
| 阻尼 | `damping` | |
| 拉伸 | `distanceConstraint.stiffness`（0–1） | |
| 光泽、透明度 | URP 材质，不进布料解算 | 粒子半径 `radius` = 0.02 |

摩擦和按品种的迭代次数不写入。身体碰撞用 `MagicaCapsuleCollider`。自碰撞只在质量档「极致」打开。

## 3. 质量档

| 档 | 实时布料 | 场合 |
|---|---|---|
| 极致 | 外、中、里、披帛，自碰撞开 | 拍照 |
| 高 | 外层和披帛 | 首发舞台目标 |
| 中 | 只留最外层 | 展厅里同时多件 |
| 低 | 关掉 MagicaCloth，只留蒙皮动画 | 最低画质。颜色和透明度仍正确 |

词条「层叠」在中档仍保留外层和披帛的实时解算。

走近展柜 3 米内，当前这一件升到高，其余保持中。舞台上同时只有一位角色使用高或极致。

## 4. 材质

每个品种一个 URP Shader Graph 主材质。实例参数：

- 底色与染层
- 色花掩膜
- 粗糙度与各向异性，区分纱、缎、麻
- 透明度
- 金线掩膜
- 结构法线（罗的孔、麻的粗糙）

湿感、水波、月华是演出临时参数。演出结束复位，不写回布匹。

## 5. 首发必须先证明的四件事

1. 素纱盖在靛蓝绸上，能看出内层颜色。
2. 同版型的素纱袖和绸袖，在同一阵侧风里延迟不同。
3. 从高切到低，颜色不变。
4. 30 秒 0 档演出不穿身、不炸布。

这四条没过，不加新品种。
