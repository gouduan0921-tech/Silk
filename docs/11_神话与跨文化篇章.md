# 神话与跨文化篇章

版本：0.5 · 2026-10-05  
主责：首发关闭的角色和形制如何挂回主链。默认 `enabled: false`；§5 起逐篇开放。

## 1. 原则

妲己、洛神、嫦娥、白素贞、克利奥帕特拉、海伦、阿佛洛狄忒、小野小町不在首发上场名单。

她们以后使用同一条织染裁缝链。差别只在版片、灯光模板和特效。底料仍是 `04` §8 里的品种。

## 2. 暂代

如果数据被误打开，又没有对应版片，角色穿襦裙，图鉴注明「形制暂代」，契合不加文化圈那 30 分。

## 3. 特效

水波、月华、白蛇披帛末端、花瓣，都是演出临时参数。不写回布匹，不增加品质，不改契合与热度。

特效从 30 档起出现；0 档只有基础演出。演出暂停时特效一起停。

- 水波：脚下一圈圈浅青色水纹向外扩开、变淡；加一盏低位冷青色边光。
- 月华：头顶一盏冷白窄光（约 7500K）；细小的光点从上缓缓落下。
- 白蛇：披帛两端拖出银白的鳞光碎点，随末端移动、渐隐。没穿披帛时从两手高度拖出。
- 花瓣：桃红花瓣绕身盘旋着落下。
- 海沫：脚边细白的泡沫一粒粒升起、变小、消散。

## 4. 关闭时的界面

上场门不显示这些角色。图鉴里以剪影存在，正文未解锁。
