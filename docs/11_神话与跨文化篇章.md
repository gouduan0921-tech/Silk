# 神话与跨文化篇章

版本：0.2 · 2026-10-02  
主责：首发关闭的角色和形制如何挂回主链。默认 `enabled: false`。

## 1. 原则

妲己、洛神、嫦娥、白素贞、克利奥帕特拉、海伦、阿佛洛狄忒、小野小町不在首发上场名单。

她们以后使用同一条织染裁缝链。差别只在版片、灯光模板和特效。底料仍是 `04` §8 里的品种。

## 2. 暂代

如果数据被误打开，又没有对应版片，角色穿襦裙，图鉴注明「形制暂代」，契合不加文化圈那 30 分。

## 3. 特效

水波、月华、白蛇披帛末端、花瓣，都是演出临时参数。不写回布匹，不增加品质。

## 4. 关闭时的界面

上场门不显示这些角色。图鉴里以剪影存在，正文未解锁。
