# 升级与成长

版本：0.2 · 2026-10-02  
主责：等级打开什么。经验公式和门槛见 `04` §7。

## 1. 等级

经验只来自完成工序。打开界面不加经验。

| 等级 | 打开 | 首发 |
|---|---|---|
| 1 | 家蚕、平纹、素纱与绢、靛蓝与茜草、襦裙、西施 | 是 |
| 2 | 绸、栀子、细方格花本 | 是 |
| 3 | 赵飞燕与王昭君的 0 档、委托刷新 | 是 |
| 4 | 素缎、宋风、直裾、红花、槐米、李清照 | 工艺章 |
| 5 | 提花花本、花缎、大袖衫、褙子、苏木、皂斗、杨贵妃 0/30 | 工艺章 |
| 6 | 云锦、改机、明风、袄裙、绿矾 | 工艺章 |
| 7 | 缂丝、西施 70 档 | 高阶织物 |

汉风从 1 级可用。其他朝代风格随上表。「工艺章」「高阶织物」是首发之后按 `01` §7 依次开放的阶段。30 档以上的档位要在本表单独写明才开放（例如 7 级的西施 70 档）；只写角色名时开放 0 与 30 档（不超过 `16` 的档位上限）。

## 2. 教学委托

前三个固定，不占用随机刷新：

1. 用开局的丝再缫或直接确认库存，织一匹绢。
2. 把布 A 或新绢染靛蓝，做成襦裙。
3. 西施穿上，完成 0 档，放入展柜。

第 1 个工坊日必须能完成第 2 和第 3 步里的演出。因此开局已经有一匹绢，见 `04` §1；第 1 个工坊日是教学日，工时见 `04` §2。

## 3. 日常委托

1 级每天 0 个。3 级起每天刷新 2 个，同时最多持有 3 个，期限 3 天。过期不掉级。

委托检查成品字段，不检查中间失败次数。交出去的物品从图鉴保留，从仓库移到委托记录。

## 4. 不会成长的东西

好感不提供属性点。等级不提高布的风力。布只由工序和 `04` 的表决定。
