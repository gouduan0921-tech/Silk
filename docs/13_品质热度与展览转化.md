# 品质热度与展览转化

版本：0.2 · 2026-10-02  
主责：公式的结构。系数、阈值、丝钱折算全部在 `04` §4、§6、§10。

## 1. 品质

Q 由七项过程分加权。缺项用 `04` 规定的默认分，不把缺项当成 0。

档位只决定在参数区间里取低、中、高。不另造一套物理。

## 2. 词条

最多 3 个。分数线和效果见 `04` §6。这里只记含义：

| 词条 | 含义 |
|---|---|
| 蝉翼 | 素纱或花纱，原料和织造都够高 |
| 流光 | 织造够高，且组织是缎或锦。首发不会出现 |
| 活色 | 染色不均落在配方允许的范围，不是失误色花 |
| 层叠 | 缝制够高且至少两层 |
| 合制 | 朝代与形制匹配，裁剪够高 |
| 越代 | 用了该朝代不典型的品种。首发汉风加三种丝织，不产生越代 |

实现时词条判定函数读取 `04` §6 的常量表。

## 3. 热度

热度描述这一次演出，不回写布匹。阶段分把低档演出的上限压住，避免只刷品质就拿满热度。

## 4. 展览

展览分不提高 Q。它只产生每天一次的丝钱，以及 80 分以上的一份普通染料或缝线。95 分以上点亮一条图鉴短讯。

首发单柜预览不计分，见 `09`。
