# 核心玩法循环与系统框架

版本：0.2 · 2026-10-02  
主责：地点、工时、季节、工序顺序、系统边界。耗时数字见 `04` §2。

## 1. 地点

首发只有一条链，快旅界面可以先做成走廊上的门。完整版本的七个地点是：桑园蚕房、织机坊、染坊、裁缝阁、市集、舞台、博物馆。

| 地点 | 能做 | 不能做 |
|---|---|---|
| 蚕房 | 养蚕、缫丝、绩麻 | 染色、裁衣 |
| 织机坊 | 整经、织布 | 养蚕 |
| 染坊 | 浸染、晾干、砑光 | 改纤维 |
| 裁缝阁 | 裁、缝、人台 | 改染料配方 |
| 市集 | 买卖、接委托、结束今天 | 制作 |
| 舞台 | 选人、选衣、演出、拍照 | 改衣服结构 |
| 博物馆 | 布展、回看 | 制作 |

成衣可以从人台直接送到舞台或展柜。

## 2. 一天

一个工坊日 8 工时。工序消耗见 `04` §2。用完可以结束今天。演出和布展不耗工时。

季节每 6 天一换，顺序春夏秋冬。季节只影响尚未入库的原料和新鲜染料，不改写已经下机的布。

| 季 | 家蚕 | 染料 |
|---|---|---|
| 春 | 最好 | 槐米、幼靛 |
| 夏 | 易热损 | 靛蓝、红花最浓 |
| 秋 | 中等 | 茜草、栀子、皂斗 |
| 冬 | 不结新茧 | 只用干料 |

3 级之前只有春。3 级起季节开始轮转（`04` §3）。新鲜染料只卖等级已开放的染料。

## 3. 制作顺序

1. 备料
2. 成纱
3. 织造
4. 染色或后整理（可跳过）
5. 裁剪
6. 缝制
7. 人台
8. 演出或入藏

取消工序：消耗一半工时，产物降一档或变成残次，上一步的物品保留。

拆衣：布匹回仓库，染色保留，边损 +1。边损达到 2 的布不能做传世外层。规则的扣分见 `04` §5。

## 4. 系统边界

| 系统 | 写入 | 只读 |
|---|---|---|
| 养蚕缫丝 | 纱线 | — |
| 织造 | 布匹的品种、织造分、花本 | 纱线 |
| 染色 | 染层、后整理 | 布匹 |
| 解算 | `cloth` 最终参数 | 上列字段和 `04` |
| 裁缝 | 成衣、过程分 | `cloth` |
| 演出 | 演出记录 | 成衣拷贝、角色 |
| 展览 | 展位、当日结算 | 成衣、演出 |

只有解算模块能写 `cloth`。演出里的历史还原和视觉增强作用在拷贝上。

## 5. 失败仍留下东西

- 断头多的丝可以织绢，不能织传世素纱。
- 色花是掩膜，不是删布。
- 缝坏的衣服能穿，袖子使用更低的拉伸刚度，见 `04` §5。
- 角色不拒绝衣服。契合低只减少热度和好感增长。

## 6. 首发开局

写死在起始存档，数字见 `04` §1。玩家不从空仓库开始，避免第一天还没衣服可看。
