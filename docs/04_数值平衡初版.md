## 4. 品质

过程分 0–100。成衣：

```text
Q = 原料×0.15 + 成纱×0.10 + 织造×0.25 + 染色×0.15 + 后整理×0.05 + 裁剪×0.15 + 缝制×0.15
```

未染色，染色分记 70。未后整理，后整理分记 60。

多层权重：外 0.5，中 0.3，里 0.2。

布匹 Q：只取原料、成纱、织造、染色、后整理五项，权重按上式归一。布匹还没做成衣时，用它取 cloth 的区间位置 t。披帛算外层附件，不替代主衣外层。高透明外层下，里层可见，此时用好布做里层不扣浪费分。

| Q | 档 | 区间位置 t |
|---|---|---|
| 0–59 | 普通 | Q / 59 × 0.35 |
| 60–84 | 精良 | 0.45 + (Q − 60) / 24 × 0.25 |
| 85–100 | 传世 | 0.75 + (Q − 85) / 15 × 0.25 |

参数 = 低端 + (高端 − 低端) × t。再乘朝代偏移，再加染色修正，最后夹回该行区间。

朝代偏移（乘在已取值上，夹紧前）：

| 朝代 | 密度 | 弯曲 | 风力响应 | 光泽 |
|---|---|---|---|---|
| 汉 | ×0.80 | ×0.60 | ×1.30 | ×0.90 |
| 唐 | ×1.00，轻的可 ×0.85、重的可 ×1.15 | 同左 ±30% 取品种默认 | ×1.00 | ×1.15 |
| 宋 | ×0.95 | ×0.90 | ×1.10 | ×0.95 |
| 明 | ×1.15 | ×1.25 | ×0.85 | ×1.10 |
| 希腊 | ×0.85 | ×0.70 | ×1.25 | ×0.95 |
| 埃及 | ×0.90 | ×0.80 | ×1.10 | ×1.05 |
| 平安 | ×1.10 | ×1.15 | ×0.80 | ×1.00 |

首发三种品种只用汉偏移。宋的行在工艺章启用（大袖衫、褙子），明的行在工艺章启用（袄裙）。希腊的行在篇章启用（希顿）：宽幅长衣垂得软、随风大。埃及的行在篇章启用（卡拉西里斯）：贴身细褶，略挺。平安的行在篇章启用（十二单）：层多而重，风里只动袖和后摆。唐的行未启用。

呈现模式再夹一次显示拷贝：

| 模式 | t 的限制 | 舞台同步强度上限 |
|---|---|---|
| 历史还原 | t ≤ 0.55，光泽再 ×0.90 | 40% |
| 标准 | 不额外限制 | 70% |
| 视觉增强 | t ≥ 0.70，薄纱风力再 ×1.10 | 100% |

视觉增强也不能超出该行高端。

## 5. 扣分与修正

| 事件 | 数字 |
|---|---|
| 缫丝断头一次 | 手稳 −8 |
| 织造一段中「乱」超过 20% | 该段 ≤ 60 |
| 花本选错 | 花位分 0 |
| 纹样方向转了 90 度 | 裁剪 −10 |
| 拼缝落在衣身正面 | 裁剪 −15 |
| 传世布做里层且外层普通、外层不透 | 裁剪 −10 |
| 缝序错一次 | 缝制 −12 |
| 未打开人台就入库 | 缝制 −5 |
| 缝制分 < 50 | 该部件拉伸刚度取该行低端 |
| 边损每 1 | 拉伸取低端，光泽 −0.2（10 分制） |
| 边损 ≥ 2 | 不能做传世外层 |
| 拆衣 | 边损 +1，染色保留 |

织造分 = 节奏×0.6 + 密度稳定×0.25 + 花位×0.15。无花位时花位按 100。

染色：

```text
浓度系数：淡 0.35，中 0.60，浓 0.85。新鲜染料浓度系数 × 1.15
强度 = min(0.85, 浓度系数 × 时间吻合 × 温度吻合)
染色分 = 温度吻合×40 + 时间吻合×30 + 搅拌稳定×30
新颜色 = 旧颜色 × (1 − 强度×0.85) + 染料色 × (强度×0.85)
```

最多 4 层。第 5 层挤掉最早一层，染色分 −10。

染色和后整理直接加在 §8 的 MagicaCloth 字段上，加完再夹回该行。

| 处理 | 阻尼 `damping` | 弯曲 `angleRestoration.stiffness` | 光泽（10 分制） |
|---|---|---|---|
| 每层植物染 | +0.005 | +0.02 | −0.4 |
| 浓档额外 | +0.008 | +0.02 | −0.3 |
| 第 2 层起 | +0.003 | 0 | −0.2 |
| 绿矾 | +0.005 | +0.02 | −0.2 |
| 砑光 | −0.005 | −0.02 | +1.2 |
| 金线掩膜内 | 0 | 弯曲 ×1.08 | +1.0 |

透明度系数 = 1 − 0.08 × 层数 × 平均强度。染色不提高透明度。

节奏窗口：±120 毫秒为稳，±240 毫秒为偏，超出为乱。

节拍间隔 0.9 秒，错过一拍超过偏的窗口记乱。节拍分：稳 100，偏 70，乱 30。织造每段 8 拍，四段共 32 拍；节奏分为各拍平均，再按上表封顶。密度稳定 = 全匹稳拍比例 × 100。缝制每个部件 12 针，缝制分为各针平均，再按上表扣分。裁剪分从 100 起扣。

残布线：织造分 < 40。

每浸染一匹耗所选干染料 1 份。

染缸操作到吻合度：

| 操作 | 规则 |
|---|---|
| 水温 | 冷、温、热三档。首发三种干染料最佳为温。最佳档吻合 1.0，其余 0.6 |
| 起布 | 提示带宽 2 秒，带中心在入缸后：淡 4 秒，中 6 秒，浓 8 秒。带内吻合 1.0，带外每偏 1 秒减 0.2，最低 0.2 |
| 搅拌 | 入缸后按节拍间隔持续搅拌，直到起布。总拍数 = 入缸到起布之间经过的节拍数（第一拍在入缸后一个间隔）。搅拌稳定 =（稳拍数 + 偏拍数 × 0.5）÷ 总拍数。未搅拌记 0 |

不均 = 1 − 搅拌稳定。不均 ≤ 0.3 为配方允许的不均；其中 ≥ 0.1 可得「活色」。不均 > 0.3 记失误色花，写掩膜。

## 10. 展览

```text
展览分 = 平均品质×0.4 + 主题一致×0.3 + 说明完整×0.1 + 影像×0.2
```

少于 2 件不能开幕。空位不扣主题分。每天只结算一次。

四项都是 0–100：

| 项 | 算法 |
|---|---|
| 平均品质 | 展出成衣取成衣 Q，展出布匹取布匹 Q，求平均 |
| 主题一致 | 「一色」：最后一层染料相同的件数占比 × 100；「从蚕到丝」：柜内同时有布与成衣，且说明牌都开了原料，为 100，否则 0 |
| 说明完整 | 各展位说明牌三项开关打开的比例 × 100 |
| 影像 | 展出成衣中有演出记录的比例 × 100 |

## 11. 取整

凡是显示给玩家的整数，四舍五入，0.5 进一。参数写进布料配置时保留三位小数，不在界面第一层展示。
