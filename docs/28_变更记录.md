# 变更记录

## 0.8 · 2026-10-05

开始写正式代码时补齐手册缺口，均以 `04` 为数字主责：

- 首日工时：`04` §2 定第 1 个工坊日为教学日，工时 13，只此一天。解开首日 10–12 工时超出 8 工时的冲突；`10` §2 引用。
- 开局物品补原料分、成纱分、接头（`04` §1），首件成衣的 Q 可以算出。
- 每浸染一匹耗 1 份干染料；染缸操作换成吻合度的规则；不均、活色与失误色花的界线；节拍分、每段拍数、每部件针数、裁剪起分、残布线（`04` §5）。
- 染料色与未染底色（`04` §5）；透明度与光泽换算材质的系数（`03` §4）。透明度按平方换算，使绸、绢接近不透、只有纱真正透光；灰盒探针里线性换算让绸也透出 25%，不符合 `01` 支柱 1。
- `21`：根加 `hoursUsed`；布匹加 `materialScore`、`yarnScore`；染层加 `concentration`；写明 fiber 取值。
- `05`：写全 19 个品种 id，加 `liningOnly`，写明教学委托 id。
- `04` §2 纱长与布长、缫丝出纱；§3 蚕箔与缫丝；§4 布匹 Q；§7 经验何时给；§10 展览四项算法。`04` §9 首发四条时间轴的段落长度（演出时长不再无据可依，也不沿用界面样板的 12 秒观看长度）。`12` §3 写明键位。襦裙加可选衬里（`07` §3，用量见 `04` §2）：否则首发的苎麻（仅衬里）和 F2「染坏仍能做里层」都无处可用。`04` §7 干栀子与靛蓝、茜草同价（原表漏了首发第三种染料）。`09` 首发一柜两个展位，使 F5 的「两件开幕」在首发可达。`21` 染层加 score、布匹加 dyePenalty、展位结构。
- 运行时走查补记：`04` §5 写明搅拌持续到起布、总拍数为其间经过的节拍数。原表未给拍数，代码曾写死 8 拍，使最好的起布时刻（中 6 秒）前搅不完，满分玩家也被记不均。

## 0.7 · 2026-10-05

`21` 升到 0.3，在 schema 1 内补三处存放位置：根下 `dyes`（染料库存）、`tray` 与 `cocoons`（蚕箔与茧篮）、`pieces`（已裁未成衣的衣片），并补写入点。尚无已发布存档，schema 仍为 1，不做迁移。

起因：首日结束时要留下干靛蓝 1 份、干茜草 1 份和未缝披帛，离开工位即写盘，而 0.2 的根字段放不下它们。不改任何数字；每次浸染耗几份染料仍待 `04` 补。

## 0.3 · 2026-10-03

技术基线从 Unreal Engine 5 + Chaos Cloth 改为 Unity 6 + MagicaCloth 2，渲染用 URP。玩法分数、丝钱、好感、工序不改。`doc/` 里的 Chaos 长表仍然只是散稿。

布料表按 MagicaCloth 2 的取值重写，见 `04` §8，写入字段见 `03` §2。每一行的高低比照旧表保留，朝代乘子仍先乘再夹回该行。

- 密度改为 `gravity`，旧值 × 13.85，使云锦高端落到 9。
- 风力改为 `wind.influence`，旧值 × 0.8，使素纱高端落到 2。
- 弯曲改为角度还原刚度。高低比不变，中心放到纱偏软、锦偏硬的 0–1 带里；高端超过 1 时夹到 1，低端改为 `1 / 原比值`。
- 距离刚度和阻尼按组改到 0–1 量级。摩擦和按品种的迭代次数不再写入解算器。
- 植物染、砑光对阻尼和弯曲的增量改到新量级。光泽加减仍是 10 分制。

演出时间轴改为 Unity Timeline。风源改为 MagicaWindZone。

## 0.2 · 2026-10-02

`doc/` 里的 0.1 散稿保留原样，包括面料长表、分镜散文和一版体系说明。那些文件不再作为配置源。本手册按《丝瓜络工坊》0.3 的写法重排：一处主责、数字只在 `04`、首发范围写死、阅读器从 Markdown 生成。

### 1. 收束

| 0.1 的情况 | 0.2 的处理 |
|---|---|
| 面料数字同时写在多份长表里 | 区间以 `04` §8 为准 |
| 19 位角色的 70 档分镜写成已可制作 | 首发只做三位的低档。分镜散文不删除，但不驱动排期 |
| 织机、染缸、舞台都像要实时仿真 | `03` 规定只有人台、舞台和近处展柜用 Chaos Cloth |
| 品质公式出现在多处 | 结构在 `13`，系数在 `04` |
| 神话角色和汉服角色混在首发名单 | `11` 默认关闭 |

### 2. 保留的设计

- 从原料到成衣再到演出、展览的顺序。
- 0 / 30 / 70 三档。
- 历史还原和视觉增强不改仓库原件。
- 植物染不上纯色，素纱要能透出内层。
- 云锦、缂丝、改机是后期品种，不是首发内容。

### 3. 尚未验证

`04` 的初值没有实机帧率，也没有外部试玩。P1 探针之后只改 `04` 和本文件，不在散稿里另改一套数字。
