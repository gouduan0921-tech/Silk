## 3. 纱线

id，fiber，fineness，processScore，materialScore，joints，length。

fiber 取值：jiaCan（家蚕）、yeCan（野蚕）、zhuMa（苎麻）、daMa（大麻）、ge（葛）、mian（棉）。首发只有 jiaCan 与 zhuMa。

## 4. 布匹

id，variety，dynastyStyle，yarnId，materialScore，yarnScore，length，width，weaveScore，patternId，dyeLayers，finish，edgeDamage。

materialScore 与 yarnScore 在下机时从所用纱线拷入（原料分、成纱过程分），开局布 A 取 `04` §1。成衣的原料分与成纱分从外层部件的布匹取。

`cloth` 可以不存。读档时按 `03` 的顺序重算。若某件需要锁死外观，另存 `clothLocked`。

dyeLayers 一层：dyeId，concentration，strength，uneven，score，maskId。score 为这一层的染色分。布匹另存 dyePenalty：挤层扣分累计。布匹染色分 = 各层 score 平均 + dyePenalty，夹在 0–100。concentration 为 light / medium / strong，用于 `04` §5 的浓档修正，读档重算 cloth 时需要。

## 5. 成衣

id，name，pattern，dynastyStyle，parts，scores，tier，traits，previewSeen。

parts：slot，boltId，lengthUsed，cutScore，sewScore。

## 6. 写入点

| 时刻 | 写入 |
|---|---|
| 下机、出缸、入库 | 对应物品 |
| 出缸 | dyes 扣减 |
| 裁一个部件 | pieces 新增 |
| 缝一个部件 | 对应 pieces 的 sewScore |
| 人台确认成衣 | 用到的 pieces 移入 garments.parts |
| 离开工位 | 整档 |
| 工坊日结束 | dayIndex、养蚕日结算（tray、cocoons） |
| 演出结束 | performances |
| 每日首次开馆 | exhibit.lastPaidDay |

## 7. 呈现模式

存在根上，也允许单件覆盖。覆盖不修改 bolts 里的染层。

## 8. 染料

dyeId，count，state。

state 为 dry 或 fresh。首发只有 dry。每次浸染扣多少份见 `04`。

## 9. 蚕箔与茧

首发一张蚕箔。`tray` 只有一个对象，空箔时 stage 为 empty。

tray：stage，startDay，lastStepDay，shellScore，uniformity，shapeScore，sick。

stage 依次为 empty、hatched、fed、tempered、mounted，对应 `06` §2 的四步。各项加减分见 `04` §3。

cocoons 一篮：id，shellScore，uniformity，shapeScore，batch，defect。batch 是还能缫几束，缫一次减一。defect 为 true 即残次茧，用途见 `06` §2。

## 10. 衣片

已经裁下、还没收成成衣的部件。

id，slot，boltId，lengthUsed，sizeClass，cutScore，sewScore。sizeClass 为 narrow / standard / wide（`07` §3 衣长与袖宽三档）。

sewScore 未缝时为空。人台确认成衣时，用到的衣片按 §5 parts 的字段移入成衣，并从 pieces 删除。没用到的衣片留在 pieces，例如首日未缝的披帛。
