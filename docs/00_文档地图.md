# 《华裳·从蚕到神》文档地图

版本：1.0 · 2026-10-05  
状态：设计基线。数值尚未实机验证。此前散稿在 `doc/`，不作为配置源。变更见 `28`。

产品名：《华裳·从蚕到神》。英文名：Silk to Divinity。工程代号：HuaShang。  
技术基线：Unity 6 + MagicaCloth 2。渲染用 URP。角色与服装经 Blender 导出 FBX，贴图在 Krita 绘制。工具分工见 `29`。  
首发平台：电脑端（键鼠）。主机不约束首发规则。

## 1. 一段话读懂 0.2

玩家在一条能看清的工艺链上做衣服：养蚕、缫丝、织布、染色、裁缝。做成的衣服穿到美人身上，在戏台上走一段短演出，再放进博物馆。布的差别必须能看出来。织机不模拟每一根经线。人台、舞台和近处展柜用 MagicaCloth 2。

## 4. 统一术语

| 词 | 含义 |
|---|---|
| 工坊日 | 一天。8 工时。不绑定现实时钟 |
| 工时 | 工序消耗的节拍。见 `04` §2 |
| 季 | 6 个工坊日。春夏秋冬循环 |
| 束 | 一束纱线，原料单位 |
| 匹 | 一块下机的布，默认 8 米、幅宽 50 厘米 |
| 件 | 一件成衣，由部件组成 |
| 品种 | 素纱、绢、绸等 19 种织物品类。物理行见 `04` §8 |
| 朝代风格 | 汉、唐、宋、明。用来夹紧参数和推荐形制 |
| 过程分 | 某一道工序的 0–100 分。界面默认不展示精确值 |
| 品质 Q | 成衣总分。档位：普通、精良、传世 |
| 词条 | 由高分过程生成，最多 3 个 |
| 档位 0 / 30 / 70 | 演出强度，由好感打开 |
| 契合 | 衣服与角色偏好的匹配，0–100 |
| 热度 | 一次演出的成绩，不改布料参数 |
| 丝钱 | 唯一货币 |
| 呈现模式 | 历史还原 / 标准 / 视觉增强。只改显示拷贝，不改仓库原件 |
| 残次 | 过程分过低的丝或布。能用，不能做传世外层 |

## 5. 现实与虚构

- 纤维、组织和染料名参照公开的纺织史常识：素纱禅衣、罗、绫、缎、锦、缂丝、植物染。游戏里的分数和米数是节奏设定，不是考古计量。
- 时间是压缩的。文案不写现实里养一季蚕要多少天。
- 不写化工漂白，不写化纤光泽。
- 神话角色和跨文化角色可以加特效，底料仍用真实纤维。首发不投放，见 `11`。
- 演出展示衣服和人物气质，不做低俗镜头。

## 6. 首发范围

**首发可玩：**

- 一条工位链：蚕房、平纹织机、一口染缸、裁桌、人台、古典戏台、一个展柜、委托牌
- 家蚕、苎麻
- 品种：素纱、绢、绸
- 染料：靛蓝、茜草、栀子
- 形制：襦裙
- 角色：西施（0 与 30）、王昭君（0）、赵飞燕（0）
- 舞台：古典戏台
- 工艺 1–3 级
- 历史还原 / 标准 / 视觉增强

**首发不做：**

- 每一根经线的布料粒子
- 整座染坊的三维流体
- 云锦、缂丝、改机
- 19 人同时拥有 70 档语音
- 自由打版
- 联机参观
- 付费跳过工序

**预留配置、首发关闭：** 神话与跨文化篇章、水墨台、现代剧场、活动、分享、内购。
