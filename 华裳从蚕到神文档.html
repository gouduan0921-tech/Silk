文档 00

《华裳·从蚕到神》文档地图

版本：0.3 · 2026-10-03
状态：设计基线。数值尚未实机验证。此前散稿在 doc/，不作为配置源。变更见 28。

产品名：《华裳·从蚕到神》。英文名：Silk to Divinity。工程代号：HuaShang。
技术基线：Unity 6 + MagicaCloth 2。渲染用 URP。角色与服装经 Blender 导出 FBX。
首发平台：电脑端（键鼠）。主机不约束首发规则。

1. 一段话读懂 0.2

玩家在一条能看清的工艺链上做衣服：养蚕、缫丝、织布、染色、裁缝。做成的衣服穿到美人身上，在戏台上走一段短演出，再放进博物馆。布的差别必须能看出来。织机不模拟每一根经线。人台、舞台和近处展柜用 MagicaCloth 2。

5. 现实与虚构

  • 纤维、组织和染料名参照公开的纺织史常识：素纱禅衣、罗、绫、缎、锦、缂丝、植物染。游戏里的分数和米数是节奏设定，不是考古计量。
  • 时间是压缩的。文案不写现实里养一季蚕要多少天。
  • 不写化工漂白，不写化纤光泽。
  • 神话角色和跨文化角色可以加特效，底料仍用真实纤维。首发不投放，见 11。
  • 演出展示衣服和人物气质，不做低俗镜头。

6. 首发范围

首发可玩：

  • 一条工位链：蚕房、平纹织机、一口染缸、裁桌、人台、古典戏台、一个展柜、委托牌
  • 家蚕、苎麻
  • 品种：素纱、绢、绸
  • 染料：靛蓝、茜草、栀子
  • 形制：襦裙
  • 角色：西施（0 与 30）、王昭君（0）、赵飞燕（0）
  • 舞台：古典戏台
  • 工艺 1–3 级
  • 历史还原 / 标准 / 视觉增强

首发不做：

  • 每一根经线的布料粒子
  • 整座染坊的三维流体
  • 云锦、缂丝、改机
  • 19 人同时拥有 70 档语音
  • 自由打版
  • 联机参观
  • 付费跳过工序

预留配置、首发关闭： 神话与跨文化篇章、水墨台、现代剧场、活动、分享、内购。

文档 01

《华裳·从蚕到神》游戏总体策划案

版本：0.2 · 2026-10-02
主责：产品定位、体验支柱、范围与成功标准。系统细则见 02 起；所有数字见 04。

1. 一句话

从蚕茧做成一匹布，裁成衣服，穿到人身上走一段演出，再放进展柜。两件衣服如果原料或染法不同，舞台上必须看得出来。

2. 定位

项决定
类型单人 3D 工艺模拟。生产链 + 短演出 + 收藏
参照体验手作的步骤清楚；布料在身上的差别看得见；展览是归宿，不是商店评分板
气质安静、材料真实、舞台有节奏。风格名「一幅素纱」
场地首发是一条工位链，不是开放世界。完整愿景是七个地点快旅，见 02
单次用现成丝做一条襦裙并看完 0 档演出，约 20–40 分钟
中期一季 6 日。春茧、夏染、秋织可以跨天
长线首发工艺 1–3 级。云锦和其余角色在首发之后
平台电脑端首发，键鼠
团队内容数据驱动。布料参数只来自配置表

3. 目标用户

  • 想看见「自己做的布」和别人的布不一样的人。
  • 在意汉服结构和纺织名词，但不要求学术论文的人。
  • 愿意为一次 30 秒的演出停下来看衣服的人。

不作为设计前提：开放世界探索、数值养成刷好感、换装拍照作为唯一玩法、强社交。

4. 体验支柱

每条都要能验收，见 26。

  1. 布是结果，不是皮肤。 品种、染色、缝制失败会改变垂坠、透光或拉扯。换一件衣服不是只换颜色贴图。
  2. 工序能停。 染坏的布还是布，可以改作衬里。拆衣退回布匹，见 02。
  3. 决定少而硬。 每天要定的事：这束丝织什么、染多深、布放在哪一层、给谁穿、用哪种呈现。重复的晾晒由时间结算。
  4. 舞台为衣服服务。 0 档没有粒子也能看清轮廓。70 档才是完整分镜。
  5. 展览说得清来历。 说明牌能指出原料、染料和是否符合朝代，不能把普通布写成出土文物。
  6. 可中断。 离开工位即写盘。呈现模式不改仓库里的原件。

5. 核心循环一览

TEXT
每日：看季节与库存 → 养蚕或取丝 → 织 → 染 → 裁缝 → 人台
     → 演出或入柜 → 工时用尽则下一天
一季：原料窗口变化。春茧细，夏蓝浓，秋染料全，冬不结新茧
长线：工艺等级打开组织和角色 → 更好的布进同一条链 → 展览主题

细则见 02。

6. 商业模式

首发是完整单机，买断制。丝钱只在玩法内循环。不能用钱买成品锦、成衣或好感。广告、内购、DLC 见 25，默认关闭。

阶段玩家得到什么依赖

8. 成功标准

首日：

  • 从开局已有的一匹绢开始，做成靛蓝襦裙，西施完成 0 档演出，衣服出现在展柜。
  • 同一天里，蚕箔或织机上还有一件未完成的东西。

首季：

  • 玩家见过季节对茧或染料的影响。
  • 玩家有过一次染色失误或缝制失误，并且在人台或舞台上看得见。

理解度： 玩家能说出

  • 这件衣服的外层是什么品种
  • 为什么它透或者不透
  • 这次演出是 0 档还是 30 档
  • 展柜里的说明牌对应哪一道工序

无障碍： 关掉音乐后，织机和缝制仍有操作声。字幕默认开启。

文档 02

核心玩法循环与系统框架

版本：0.2 · 2026-10-02
主责：地点、工时、季节、工序顺序、系统边界。耗时数字见 04 §2。

1. 地点

首发只有一条链，快旅界面可以先做成走廊上的门。完整版本的七个地点是：桑园蚕房、织机坊、染坊、裁缝阁、市集、舞台、博物馆。

地点能做不能做
蚕房养蚕、缫丝、绩麻染色、裁衣
织机坊整经、织布养蚕
染坊浸染、晾干、砑光改纤维
裁缝阁裁、缝、人台改染料配方
市集买卖、接委托、结束今天制作
舞台选人、选衣、演出、拍照改衣服结构
博物馆布展、回看制作

成衣可以从人台直接送到舞台或展柜。

2. 一天

一个工坊日 8 工时。工序消耗见 04 §2。用完可以结束今天。演出和布展不耗工时。

季节每 6 天一换，顺序春夏秋冬。季节只影响尚未入库的原料和新鲜染料，不改写已经下机的布。

季家蚕染料
春最好槐米、幼靛
夏易热损靛蓝、红花最浓
秋中等茜草、栀子、皂斗
冬不结新茧只用干料

首发只启用春，以及靛蓝、茜草、栀子的干料。夏秋冬的行留在表里，等级未到不出现。

3. 制作顺序

  1. 备料
  2. 成纱
  3. 织造
  4. 染色或后整理（可跳过）
  5. 裁剪
  6. 缝制
  7. 人台
  8. 演出或入藏

取消工序：消耗一半工时，产物降一档或变成残次，上一步的物品保留。

拆衣：布匹回仓库，染色保留，边损 +1。边损达到 2 的布不能做传世外层。规则的扣分见 04 §5。

4. 系统边界

系统写入只读

织造布匹的品种、织造分、花本纱线

只有解算模块能写 cloth。演出里的历史还原和视觉增强作用在拷贝上。

5. 失败仍留下东西

  • 断头多的丝可以织绢，不能织传世素纱。
  • 色花是掩膜，不是删布。
  • 缝坏的衣服能穿，袖子使用更低的拉伸刚度，见 04 §5。
  • 角色不拒绝衣服。契合低只减少热度和好感增长。

6. 首发开局

写死在起始存档，数字见 04 §1。玩家不从空仓库开始，避免第一天还没衣服可看。

文档 03

布料仿真技术实现方案

版本：0.3 · 2026-10-03
主责：哪些效果实时解算，哪些烘焙。参数区间见 04 §8。品质如何取区间见 13 与 04 §4。

1. 两层仿真

层玩家在做什么实现
工艺养蚕、抽丝、织、染、裁、缝规则、动画、计分。结果写入物品
视觉人台、舞台、近处展柜MagicaCloth 2 的 MeshCloth + URP 材质实例

织机上的经线是动画和节拍，不是成千上万的布料粒子。染缸只在特写镜头里做液面。布离开染缸后，颜色烘焙进纹理。

2. 参数从哪来

顺序固定：

  1. 按品种取 04 §8 的区间。
  2. 按品质档取区间内的位置 t。
  3. 乘朝代偏移。
  4. 夹紧到该品种区间，不允许漂出表外。
  5. 加染色和后整理修正。
  6. 金线掩膜只改局部光泽和局部弯曲。
  7. 边损和缝制失败覆盖拉伸。

舞台加载时如果呈现模式不是标准，在拷贝上再夹一次，不写回仓库。

写入 MagicaCloth 2 时，每个服装部件一个组件。改 SerializeData 后调用 SetParameterChange()。

04 的列写入字段首发固定、不按品种分的项
密度gravity（0–10）gravityFalloff = 0
弯曲angleRestorationConstraint.stiffness（0–1）triangleBendingConstraint.stiffness = 1
风力wind.influence（0–2）风源用 MagicaWindZone
阻尼damping
拉伸distanceConstraint.stiffness（0–1）
光泽、透明度URP 材质，不进布料解算粒子半径 radius = 0.02

摩擦和按品种的迭代次数不写入。身体碰撞用 MagicaCapsuleCollider。自碰撞只在质量档「极致」打开。

3. 质量档

档实时布料场合
极致外、中、里、披帛，自碰撞开拍照
高外层和披帛首发舞台目标
中只留最外层展厅里同时多件
低关掉 MagicaCloth，只留蒙皮动画最低画质。颜色和透明度仍正确

词条「层叠」在中档仍保留外层和披帛的实时解算。

走近展柜 3 米内，当前这一件升到高，其余保持中。舞台上同时只有一位角色使用高或极致。

4. 材质

每个品种一个 URP Shader Graph 主材质。实例参数：

  • 底色与染层
  • 色花掩膜
  • 粗糙度与各向异性，区分纱、缎、麻
  • 透明度
  • 金线掩膜
  • 结构法线（罗的孔、麻的粗糙）

湿感、水波、月华是演出临时参数。演出结束复位，不写回布匹。

5. 首发必须先证明的四件事

  1. 素纱盖在靛蓝绸上，能看出内层颜色。
  2. 同版型的素纱袖和绸袖，在同一阵侧风里延迟不同。
  3. 从高切到低，颜色不变。
  4. 30 秒 0 档演出不穿身、不炸布。

这四条没过，不加新品种。

文档 07

织染裁缝工序

版本：0.2 · 2026-10-02
主责：织、染、裁、缝何时算成功、何时留下瑕疵。所有阈值见 04 §5、§8。

1. 织

首发只有平纹机，可选素纱、绢、绸。苎麻不在这台机器上织，里层使用开局或购买的苎麻布，首发不单做绩麻小游戏。

流程：选品种、整经、四段循环、下机。

节拍打在踏板和梭上。稳、偏、乱的毫秒窗口见 04。一段里乱的比例超过阈值，该段分数被封顶。

下机得到 8 米布。花本首发只有「素」和「细方格」。选错花本时布仍在，花位分归零。

残布：织造分低于 40。可染，可做里层，不能做传世外层。

2. 染

首发染料：靛蓝、茜草、栀子。一口缸。

操作：浓度三档、水温、起布、搅拌。强度和叠色公式见 04 §5。

出缸后颜色烘焙。晾晒只播放由湿到干，不继续改配方。写入存档的是干态。

扎染、夹缬、绿矾、砑光留在表里，首发工位不提供。

色花写成掩膜。它降低染色分，不删除布匹。

3. 裁

首发形制只有襦裙：上襦、裙、可选披帛。

布可以 0 度或 90 度铺上版片。方向不对、拼缝在正面、浪费好布，扣分见 04。外层是高透明纱时，里层用好布不扣浪费。

衣长和袖宽三档：窄、标准、宽。首发标准档对应汉风，偏宽。选极端档仍可做，但拿不到「合制」。

4. 缝

沿缝推进。针距离开标记带则摩擦声变干，并扣缝制分。层序必须先里后外。

缝制分低于 50 的部件仍可穿，拉伸刚度取该品种低端。

未打开人台就入库，额外扣分，见 04。

5. 人台

使用与舞台相同的布料配置，风只用基础风，光用中性白。可以转、隐藏外层、退回缝或裁。不能在这里改染料。改色必须拆下部件回染坊。拆衣规则见 02。

6. 完成

每个可见部件都有布，缝制已确认，人台至少打开过一次（或接受扣分强行入库）。然后生成成衣。
