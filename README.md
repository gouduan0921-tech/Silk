# 《华裳·从蚕到神》 / Silk to Divinity

工程代号 HuaShang。Unity 6（6000.6.4f1）+ 通用渲染管线（URP）。用 Unity Hub 打开本目录。

设计文档在 `docs/`。`doc/` 是更早的散稿，不作为配置来源。

| 目录 | 内容 |
|---|---|
| `Assets/HuaShang/Scripts` | 游戏模块 |
| `Assets/HuaShang/Cloth` | 品种材质与布料预设 |
| `Assets/HuaShang/Patterns` | 形制与部件 |
| `Assets/HuaShang/Characters` | 角色 |
| `Assets/HuaShang/Stages` | 演出 Timeline |
| `Assets/HuaShang/Data` | 配置数据 |
